# 🔐 Ciphers — TOL Format

## 1. WHAT?

### What is a Cipher?

A **cipher** is an **algorithm that performs encryption or decryption**.

In simple words:

> **Cipher = the algorithm/rules used to transform data during encryption or decryption.**

The slide also states that **cipher is synonymous with “code.”**

### What is Ciphertext?

**Ciphertext** is the **result of encryption performed on plaintext via an algorithm**.

So:

**Plaintext → Cipher + Encryption → Ciphertext**

Example:

```text
Plaintext
   ↓
"I LOVE AWS"
   ↓
Encryption algorithm (Cipher)
   ↓
Ciphertext
"X7#K91..."
```

---

## 2. WHERE?

Ciphers are used wherever information needs to be **encrypted or decrypted**, for example:

- Secure communication
- Protecting sensitive information
- Data encryption
- Cryptographic systems
- Cloud security

In the context of AWS, ciphers are part of the underlying cryptographic mechanisms used when protecting data.

> **Important:** The slide itself focuses mainly on the definitions of **cipher, ciphertext, and codebook** rather than specific AWS cipher algorithms.

---

## 3. HOW?

### Encryption

A cipher takes **plaintext** and applies an encryption algorithm to produce **ciphertext**.

```text
        ENCRYPTION
Plaintext ───────────→ Ciphertext
              ↑
            Cipher
```

### Decryption

The cipher can also perform the reverse operation:

```text
        DECRYPTION
Ciphertext ──────────→ Plaintext
              ↑
            Cipher
```

Therefore:

> **Cipher = algorithm used for encryption/decryption**

> **Ciphertext = output produced after encryption**

# 📖 Codebook

The slide also introduces a **codebook**.

### What is a Codebook?

A **codebook** is a type of document used for **gathering and storing cryptography codes**.

The image shows an example where words/messages correspond to particular codes.

For example, conceptually:

```text
Message              Code
--------------------------
Cannot       →        00
Cannula      →        01
Cannulated   →        02
Canny        →        03
```

So someone with the appropriate codebook could interpret the codes.

### Codebook vs Cipher

| Term | Meaning |
|---|---|
| **Cipher** | Algorithm that performs encryption/decryption |
| **Ciphertext** | Result of encryption |
| **Codebook** | Document containing/storing cryptographic codes |
| **Plaintext** | Original readable information |
