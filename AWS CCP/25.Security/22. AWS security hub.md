## 🛡️ AWS Security Hub

### What is it?
**AWS Security Hub** is a **Cloud Security Posture Management (CSPM)** service.

Its purpose is to give you a centralized view of your AWS security posture and help you identify security issues.

### 🔑 Key concept: Security Score

Security Hub can generate a **security score** that helps determine your overall security posture.

Think:

> **Security Hub → Security posture → Security score**

---

## 📋 Security Standards

Security Hub allows you to enable **security standards**.

A standard is essentially a **collection of security controls**.

The slide describes these security controls as **AWS Config rules**.

Examples shown include:

- **CIS AWS Foundations Benchmark**
- **AWS Foundational Security Best Practices**
- **AWS Resource Tagging Standard**
- **NIST Special Publication 800-53**

These standards contain checks that determine whether your AWS environment follows recommended security practices.

---

## 🔎 Findings

Security Hub produces **findings** when security controls identify potential problems.

You can:

**Security control → Finding → Investigate**

For example, the slide shows findings such as:

- Hardware MFA should be enabled for the root user
- Customer-created KMS key rotation should be enabled

You can investigate each individual finding.

---

## 📊 What the dashboard gives you

The slide shows Security Hub providing:

- **Security score**
- Number of controls **passed/failed**
- Enabled security standards
- Individual **findings**
- Common **threat types**

So instead of checking security issues separately across your AWS environment, Security Hub gives you a **centralized security view**.

### 🧠 AWS Practitioner exam memory trick

**Security Hub = "How secure is my AWS environment?"**

| Service | Think |
|---|---|
| **Security Hub** | 🛡️ Central security posture |
| **GuardDuty** | 🚨 Threat detection |
| **Inspector** | 🔍 Vulnerability/security assessment |
| **WAF** | 🔥 Web application protection |
| **Shield** | 🛡️ DDoS protection |
| **KMS** | 🔑 Encryption key management |
| **CloudHSM** | 🔐 Dedicated HSM |

### ⚠️ Don't confuse these

**GuardDuty** detects suspicious/malicious activity.

**Security Hub** brings security findings and standards together and provides a **security posture/score**.

**Inspector** assesses workloads for vulnerabilities and security issues.

**Security Hub = posture. GuardDuty = threats. Inspector = vulnerabilities.**
