# 🔐 Digital Signatures & Signing — AWS Security Notes

## 1. WHAT is a Digital Signature?

A **digital signature** is a mathematical mechanism used to verify the **authenticity and integrity** of a digital message, document, or piece of data.

It helps answer:

- **Was the data modified/tampered with?**
- **Did the data actually come from the expected sender?**

### Simple Example

Alice wants to send Bob:

> `Hello Bob!`

Alice uses her **private key** to create a digital signature.

Bob uses Alice's **public key** to verify it.

```text
             Alice
               │
        "Hello Bob!"
               │
        + Private Key
               ↓
       Digital Signature
               │
               ↓
             Bob
               │
        + Alice's Public Key
               ↓
          Verification
               │
        ✅ Authentic
        ✅ Not tampered
```

### 🔑 Key idea

> **Private key → Sign**  
> **Public key → Verify**

# 3. HOW does Digital Signing work?

There are **3 main processes**:

### ① Key Generation

Generate a:

- **Public key**
- **Private key**

```text
Key Generation
      ↓
 ┌───────────┐
 │           │
Private     Public
 Key         Key
```

The **private key must remain secret**.

The **public key can be shared**.

---

### ② Signing

The sender uses their **private key** together with the message to generate the digital signature.

```text
Message
   +
Private Key
   ↓
Digital Signature
```

For example:

```text
Alice
  │
  ├── Message: "Hello Bob!"
  │
  └── Private Key
          ↓
   Digital Signature
```

---

### ③ Signature Verification

The receiver uses the sender's **public key** to verify the signature.

```text
Message + Digital Signature
             +
        Public Key
             ↓
        Verification
             ↓
       ✅ Valid / ❌ Invalid
```

If verification succeeds, Bob has evidence that:

1. The message came from the expected sender.
2. The message was not modified after signing.

# 4. Digital Signature vs Encryption

This is an **important distinction**.

| Feature | Digital Signature | Encryption |
|---|---|---|
| Main purpose | Authenticity + Integrity | Confidentiality |
| Proves sender? | ✅ Yes | ❌ Not by itself |
| Detects modification? | ✅ Yes | Not its primary purpose |
| Makes data unreadable? | ❌ No | ✅ Yes |
| Private key | Used for signing | Depends on encryption type |
| Public key | Used for verification | Can be used for encryption in asymmetric encryption |

### 🧠 Remember

> **Encryption = Keep it SECRET**  
> **Digital Signature = Prove it is AUTHENTIC**

---

# 5. Digital Signature vs Hashing

Another important distinction:

### Hashing

A hash function converts data into a fixed-size value.

```text
Data
 ↓
Hash Function
 ↓
Hash
```

Used primarily for **integrity checking**.

### Digital Signature

A digital signature uses cryptographic keys to provide stronger evidence of **authenticity and integrity**.

```text
Message
   ↓
Signing process + Private Key
   ↓
Digital Signature
   ↓
Verify using Public Key
```

### Easy memory trick

> **Hash = fingerprint of data**  
> **Signature = fingerprint + proof of signer**

# 6. Code Signing

## WHAT?

**Code signing** means using a digital signature to ensure that **computer code has not been tampered with**.

```text
Software / Code
      ↓
Digital Signing
      ↓
Signed Code
      ↓
User downloads it
      ↓
Signature Verification
      ↓
✅ Trusted / ❌ Modified
```

### WHERE?

Commonly used for:

- Software
- Applications
- Drivers
- Packages
- Executables

The purpose is to give users confidence that the software hasn't been modified after it was signed.

# 7. SSH and Digital Signatures

The material specifically mentions **SSH**.

SSH can use a **public/private key pair** to authorize remote access to a machine.

Example:

```text
Your Computer
     │
     │ SSH
     ↓
Remote Server
     │
     ↓
Public Key Verification
```

A common command for generating an RSA key pair is:

```bash
ssh-keygen -t rsa
```

### Key concept

The generated key pair consists of:

- 🔑 **Private key** → kept secret
- 🔓 **Public key** → placed/shared with the server

---

# 8. Important Terms

### Digital Signature
A mathematical scheme for verifying the **authenticity of digital messages/documents**.

### Signing
Generating a digital signature using a **private key** and the input message.

### Signature Verification
Verifying the authenticity of a message using a **public key**.

### Key Generation
Generating the **public and private keys** required for cryptographic operations.

### Tamper-evidence
Provides evidence that data has been **modified after signing**.

### Code Signing
Using digital signatures to ensure **computer code has not been tampered with**.
