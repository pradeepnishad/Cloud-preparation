# 🌐 Distributed Denial of Service (DDoS)

## 1. WHAT is a DDoS Attack?

**DDoS (Distributed Denial of Service)** is a malicious attempt to disrupt normal traffic to a website or service by **flooding it with a large amount of fake traffic**.

### Simple definition

> **DDoS = Many sources send huge amounts of traffic to a target to make the service unavailable to legitimate users.**

The key word is **Distributed**.

Instead of traffic coming from only one attacking machine, the attack uses **multiple sources** to send traffic toward the victim.

---

# 2. HOW does a DDoS attack work?

Based on the diagram:

```text
              ┌── Attacker / Source 1 ──┐
              │                          │
Attacker ─────┼── Source 2 ─────────────┤
              │                          ↓
              ├── Source 3 ───────→  Network
              │                          ↓
              └── Source 4 ─────────→ Victim
                                         ↓
                              Service disruption
```

The general flow is:

**Attacker → Multiple sources → Large amount of traffic → Victim**

The victim receives so much unwanted traffic that normal/legitimate traffic can be disrupted.

---

# 3. WHERE does the attack happen?

A DDoS attack targets a **network-accessible service**, such as a website or application.

In the AWS context shown in the image:

```text
Multiple sources
      ↓
Internet / Network
      ↓
AWS Network
      ↓
Victim
```

The **victim** is the AWS-hosted resource or service being targeted.

---

# 4. WHAT is the goal of a DDoS attack?

The goal is to **disrupt normal service availability**.

For example:

### Normal situation

```text
Users → Website
        ↓
   Website responds
```

### During DDoS

```text
Legitimate users ──────┐
                       ↓
Massive fake traffic → Website
                       ↓
                 Overwhelmed
                       ↓
              Service disruption
```

Legitimate users may experience difficulty accessing the service.

---

# 5. Why is it called "Distributed"?

### DoS

A **Denial of Service (DoS)** attack generally involves a single source attempting to overwhelm a target.

```text
Attacker
   ↓
Victim
```

### DDoS

A **Distributed Denial of Service** attack involves traffic coming from **multiple sources**.

```text
Source 1 ──┐
Source 2 ──┤
Source 3 ──┼──→ Victim
Source 4 ──┤
Source 5 ──┘
```

### 🧠 Memory trick

> **D = Distributed = traffic comes from many sources**

---

# 6. 🔐 AWS & DDoS

For AWS, DDoS protection is an important part of maintaining **availability**.

You may encounter AWS services designed to help protect applications from DDoS attacks, such as **AWS Shield**.

### Important distinction

**DDoS attack** → attempts to disrupt availability.

**DDoS protection** → attempts to detect/mitigate the attack and keep the application available.

---

# 7. DDoS vs Penetration Testing

This connects directly to the previous topic you studied.

| DDoS Attack | Penetration Testing |
|---|---|
| Attempts to disrupt availability | Tests security |
| Floods a target with traffic | Simulates attacks to identify weaknesses |
| Malicious when unauthorized | Must be authorized |
| Can affect legitimate users | Designed to evaluate security controls |

### ⚠️ AWS exam point

Just because AWS permits certain types of penetration testing **doesn't mean you can freely perform DDoS attacks or simulations**.

DDoS simulation/testing is subject to **AWS's DDoS Simulation Testing policy**.
