# 🌐 Amazon CloudFront

## 1. Definition

**Amazon CloudFront is AWS's Content Delivery Network (CDN) service.**

A CDN delivers content to users from **locations closer to them**, helping reduce latency and improve performance.

Simple idea:

```text
Without CloudFront:

User in Mumbai
      ↓
AWS origin in another location
      ↓
Content
```

With CloudFront:

```text
User in Mumbai
      ↓
CloudFront Edge Location
      ↓
Content
```

CloudFront has a globally distributed network of **edge locations** where content can be cached.

---

# 2. What is a CDN?

### Definition

A **Content Delivery Network (CDN)** is a distributed network of servers that delivers content from locations geographically closer to users.

Content can include:

* Images
* Videos
* HTML
* CSS
* JavaScript
* API responses
* Other web content

### Example

Suppose your website's images are stored in:

```text
S3
```

A user in Mumbai requests an image.

Instead of repeatedly retrieving the image from the origin, CloudFront can cache it at an edge location closer to the user.

```text
User
 ↓
CloudFront
 ↓
Cached image
```

---

# 3. What is an Origin?

The **origin** is the original location where CloudFront gets the content.

Common origins include:

* Amazon S3
* Application Load Balancer
* EC2/application server
* Other HTTP servers

Example:

```text
User
  ↓
CloudFront
  ↓
S3 bucket
```

Here:

> **CloudFront = CDN**
> **S3 = Origin**

---

# 4. What is an Edge Location?

An **Edge Location** is a location in AWS's global network where CloudFront can cache and deliver content.

Think:

```text
                  CloudFront
                Global Network
              /       |       \
             ↓        ↓        ↓
        Edge Location Edge Location Edge Location
             ↓
           Users
```

The purpose is to bring content **closer to users**.

---

# 5. How CloudFront Works

Imagine your website has an image:

```text
image.jpg
```

The first user requests it:

```text
User
 ↓
CloudFront
 ↓
Cache miss
 ↓
S3 Origin
 ↓
image.jpg
```

CloudFront retrieves the image from the origin and can cache it.

A second user requests the same image:

```text
User
 ↓
CloudFront
 ↓
Cache hit
 ↓
image.jpg
```

The content can be served from the CloudFront cache instead of going back to the origin.

### Key terms

**Cache Hit**

> Content is already available in the CloudFront cache.

**Cache Miss**

> Content isn't currently available in the cache, so CloudFront retrieves it from the origin.

---

# 6. Why Use CloudFront?

### Performance

CloudFront can reduce latency by serving cached content from locations closer to users.

### Reduce origin load

If many users request the same content, CloudFront can serve cached copies instead of sending every request to the origin.

### Global delivery

CloudFront is designed to distribute content globally.

### Security

CloudFront can integrate with AWS security capabilities such as:

* AWS WAF
* AWS Shield
* HTTPS/TLS

```text
                  CloudFront

                ↓
```

```text
/products/laptop.jpg
```

A user in Mumbai requests:

```text

```

# 8. CloudFront vs S3

This distinction is important.

### S3

**S3 = Object storage**

```text
Store:
Images
Videos
Documents
Files
```

### CloudFront

**CloudFront = Content delivery**

```text
Deliver:
Images
Videos
Web content
API responses
```

They can work together:

```text
User
 ↓
CloudFront
 ↓
S3
```

So:

> **S3 stores the content.**
> **CloudFront delivers the content efficiently.**

---

# 9. CloudFront vs Load Balancer

Don't confuse these.

### CloudFront

Primarily focuses on **global content delivery and caching**.

```text
User
 ↓
CloudFront
 ↓
Origin
```

### Load Balancer

Primarily distributes traffic across multiple backend targets.

```text
User
 ↓
Load Balancer
 ↓
EC2
EC2
EC2
```

They can also be used together:

```text
User
 ↓
CloudFront
 ↓
Load Balancer
 ↓
EC2 instances
```

---

# 10. CloudFront and Dynamic Content

CloudFront isn't only for static files.

It can also work with **dynamic content and applications**, where requests are forwarded to an origin such as an application server or load balancer.

For Cloud Practitioner, remember:

> **CloudFront is a CDN, not simply an S3 caching service.**
