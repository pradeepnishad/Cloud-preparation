## AWS Service Health Dashboard vs Personal Health Dashboard

### 1. AWS Service Health Dashboard

The **Service Health Dashboard** shows the **general status of AWS services**.

Think of it as:

> **“Is AWS having a problem?”**

It gives you the status of AWS services and indicates the status of each service using **icons and details**.

**Example:**
If Amazon API Gateway is experiencing an issue, the Service Health Dashboard can show that service's current status.

### 2. AWS Personal Health Dashboard

The **Personal Health Dashboard** provides **alerts and guidance for AWS events that might affect your specific environment**.

Think of it as:

> **“Is something happening that affects MY AWS resources?”**

According to your slide:

* **All AWS customers can access it.**
* Shows **recent events**.
* Shows **scheduled changes**.
* Provides **proactive notifications**.
* Helps you plan for scheduled activities.
* Provides guidance to **diagnose and resolve issues** affecting your AWS resources.

---

### 🔥 Easy way to remember

| Dashboard                     | Main purpose                                       |
| ----------------------------- | -------------------------------------------------- |
| **Service Health Dashboard**  | 🌎 **Overall AWS service status**                  |
| **Personal Health Dashboard** | 👤 **Events that may affect your AWS environment** |

### Exam-style question

**Q: You want to check whether an AWS service is generally experiencing an outage. Which dashboard should you use?**

✅ **Service Health Dashboard**

**Q: AWS has scheduled an event that may affect your EC2 resources. Which dashboard can provide alerts and guidance about it?**

✅ **Personal Health Dashboard**

**Shortcut:**
**Service Health = AWS in general**
**Personal Health = YOUR environment**
