### AWS Credits — Simple Explanation

**AWS Promotional Credits**, or simply **AWS Credits**, are basically like **USD balance that can be used toward eligible AWS services**.

According to your slide, you can earn credits through:

* 🚀 Joining the **AWS Activate** startup program
* 🏆 Winning **hackathons**
* 📝 Participating in **surveys**
* And other methods

### Important points

**1. Credits have an expiry date**
AWS Credits generally come with an **expiration date**. So you need to use them before they expire.

**2. Credits can be used for most AWS services**
However, there are exceptions.

The slide's example is:

> **Route 53 domain purchases cannot be paid for using AWS Credits.**

**3. Credits reduce your AWS bill**
For example, if you have **$500 in AWS Credits** and your eligible AWS usage costs $100, the credits can cover that eligible cost, leaving $400 of credit.

### 🧠 Exam shortcut

Think:

**AWS Credits = AWS money/balance**

Remember these 3 things:

> **Earn → Use → Expire**

* **Earn:** Activate, hackathons, surveys, etc.
* **Use:** Most AWS services
* **Expire:** Credits generally have an expiration date

**Important distinction:** AWS Credits are **not the same thing as the AWS Free Tier**.
Free Tier gives you eligible free usage within limits, while **Credits are promotional monetary credits** applied toward eligible charges.
