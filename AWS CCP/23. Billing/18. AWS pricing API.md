# AWS Pricing API

### 🔹 WHAT?

**AWS Pricing API** lets you **programmatically access AWS pricing information**.

Instead of manually checking the AWS Pricing page, applications can query the API to get the **latest pricing information for AWS services**.

**Main purpose:**

> Get AWS service pricing automatically through code.

---

### 🔹 WHERE?

AWS provides **two versions** of the Pricing API:

| API           | Format                 | Purpose                                    |
| ------------- | ---------------------- | ------------------------------------------ |
| **Query API** | JSON                   | Query pricing information programmatically |
| **Batch API** | Price List / JSON data | Retrieve larger pricing datasets           |

The slide shows these endpoints:

* **Query API:** `api.pricing.us-east-1.amazonaws.com`
* **Batch API:** `pricing.us-east-1.amazonaws.com/offers/v1.0/aws/index.json`

📌 **Important:** Even though the endpoint uses `us-east-1`, pricing information can be used to obtain prices for AWS services across regions.

---

### 🔹 HOW?

Your application can call the **AWS Pricing API** and request pricing information.

**Example flow:**

```text
Your Application
       ↓
AWS Pricing API
       ↓
Pricing information
       ↓
Your application uses the data
```

For example, you could build a tool that:

```text
Select EC2 instance
        ↓
Select Region
        ↓
Call AWS Pricing API
        ↓
Get current price
        ↓
Calculate estimated monthly cost
```

---

### 🔹 TWO API OPTIONS

**1. Query API**

* Uses the **Pricing Service API**
* Returns data through **JSON**
* Useful when you want to query specific pricing information.

**2. Batch API**

* Uses the **Price List API**
* Provides pricing data in a larger dataset.
* Useful when you need to retrieve/process lots of pricing information.

---

### 🔹 PRICE CHANGE NOTIFICATIONS

AWS prices can change when:

* AWS reduces prices
* New instance types are launched
* New AWS services are introduced

You can use **Amazon SNS** to receive notifications when AWS service prices change.

```text
AWS Price Change
       ↓
Amazon SNS
       ↓
Notification
       ↓
Your application / subscriber
```

---

### 🎯 EXAM POINT

> **AWS Pricing API = Programmatic access to AWS pricing information.**

Remember:

**WHAT:** Get AWS pricing programmatically
**WHERE:** AWS Pricing Service / Price List API
**HOW:** Query API → JSON | Batch API → Price List
**EXTRA:** Amazon SNS can notify you about price changes.
