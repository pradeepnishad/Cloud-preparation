# AWS CloudWatch Metrics — Notes

## 1. What is a CloudWatch Metric?

A **CloudWatch Metric** represents a **time-ordered set of data points**.

👉 It is a **variable that is monitored over time**.

**Example:**
`CPUUtilization` of an EC2 instance can be monitored every few minutes.

---

## 2. Predefined Metrics

CloudWatch provides many **predefined metrics**.

These metrics are generally **namespaced by the AWS service**.

Examples of namespaces shown:

* EC2
* EBS
* API Gateway
* Application ELB
* CloudFront
* CodeBuild
* DynamoDB
* Billing
* Events

---

## 3. EC2 Per-Instance Metrics

For EC2 instances, CloudWatch provides metrics such as:

| Metric                | Meaning                                  |
| --------------------- | ---------------------------------------- |
| **CPUUtilization**    | CPU usage                                |
| **DiskReadOps**       | Number of disk read operations           |
| **DiskWriteOps**      | Number of disk write operations          |
| **DiskReadBytes**     | Bytes read from disk                     |
| **DiskWriteBytes**    | Bytes written to disk                    |
| **NetworkIn**         | Network traffic coming into the instance |
| **NetworkOut**        | Network traffic going out                |
| **NetworkPacketsIn**  | Incoming network packets                 |
| **NetworkPacketsOut** | Outgoing network packets                 |

### Example

If you want to monitor how much network traffic an EC2 instance is receiving:

**EC2 → NetworkIn → CloudWatch Metric**

CloudWatch then plots the values over time.

---

## 4. Metric = Variable Over Time

Think of a metric like a graph:

```text
Metric Value
   │
   │       /\       /\
   │      /  \     /  \
   │_____/    \___/    \____
   └──────────────────────────> Time
```

The graph contains **data points collected over time**.

---

# ⭐ Exam Points

* **CloudWatch Metric** → A **time-ordered set of data points**
* A metric is a **variable monitored over time**
* CloudWatch has many **predefined metrics**
* Metrics are generally organized using **AWS service namespaces**
* EC2 has metrics such as:

  * `CPUUtilization`
  * `NetworkIn`
  * `NetworkOut`
  * `DiskReadOps`
  * `DiskWriteOps`
* **NetworkIn** → incoming network traffic
* **NetworkOut** → outgoing network traffic

### Easy memory trick

> **Metric = What is happening to my resource over time?**

**Metric → Measure → Monitor → Time**
