# ☁️ CloudWatch Logs — Log Events

## 1. What is a Log Event?

A **Log Event** represents a **single event in a log file**.

> Log events can be viewed within a **Log Stream**.

### Example

A Lambda log stream may contain events such as:

```text
START RequestId
records_size
failed_put_count
END RequestId
REPORT RequestId
```

Each entry represents an individual **Log Event**.

---

## 2. Log Event Structure

A log event generally contains information such as:

* **Timestamp** → When the event occurred
* **Message** → The actual log information

Example:

```text
Timestamp                    Message
2020-07-06T20:12:18          START RequestId
2020-07-06T20:12:18          records_size
2020-07-06T20:12:18          failed_put_count
```

---

# 🔎 3. Filtering Log Events

CloudWatch allows you to use **Filter Events** to filter logs.

You can filter events using:

* **Simple matching**
* **Pattern matching syntax**

### Example

Suppose your log contains:

```text
DEBUG
INFO
ERROR
DEBUG
WARNING
ERROR
```

You can use the **Filter events** search box to find a specific pattern such as:

```text
ERROR
```

CloudWatch will show the matching log events.

# 🧠 Log Stream vs Log Event

| Term              | Meaning                                                  |
| ----------------- | -------------------------------------------------------- |
| **Log Stream**    | A sequence of log events from an application or instance |
| **Log Event**     | A single event in a log file                             |
| **Filter Events** | Used to filter/search log events                         |
| **Timestamp**     | Indicates when the event occurred                        |
| **Message**       | Contains the actual log information                      |

### Easy memory trick

> **Log Stream = Collection/sequence**
> **Log Event = One entry**

```text
Log Group
    ↓
Log Stream
    ↓
┌──────────────┐
│ Log Event 1  │
│ Log Event 2  │
│ Log Event 3  │
└──────────────┘
```

### 🎯 Exam Focus

**Log Event** → A single event in a log file.

**Log Stream** → Contains a sequence of log events.

**Filter Events** → Used to filter logs using simple or pattern-matching syntax.
