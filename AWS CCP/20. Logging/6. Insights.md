# AWS CloudWatch Logs — Log Insights

## 1. What is CloudWatch Logs Insights?

**CloudWatch Logs Insights** allows you to:

> **Interactively search and analyze CloudWatch log data.**

It is useful when you need more advanced log analysis than the basic **Filter events** option.

---

## 2. Advantages of Logs Insights

### 🔹 More powerful filtering

Logs Insights provides **more robust filtering** than the simple **Filter events** feature available inside a Log Stream.

### 🔹 No need to export logs to S3

Instead of:

```text
CloudWatch Logs
      ↓
Export to S3
      ↓
Analyze using Athena
```

You can directly analyze the logs using:

```text
CloudWatch Logs
      ↓
Logs Insights
      ↓
Query & Analyze
```

---

## 3. Supports All Types of Logs

**CloudWatch Logs Insights supports all types of logs.**

It is commonly used through the **AWS Console** to perform **ad-hoc queries** against Log Groups.

### Ad-hoc query

An **ad-hoc query** is a query created to investigate or analyze something when needed, rather than being a permanently scheduled query.

---

# 🔎 4. CloudWatch Logs Insights Query Syntax

CloudWatch Logs Insights has its own query language called:

> **CloudWatch Logs Insights Query Syntax**

Example from the notes:

```text
filter action="REJECT"
| stats count(*) as numRejections by srcAddr
| sort numRejections desc
| limit 20
```

This query:

1. Filters events where the action is **REJECT**
2. Counts the rejected requests
3. Groups them by **source address (`srcAddr`)**
4. Sorts the results by number of rejections in descending order
5. Returns the **top 20 results**

---

# 📊 5. Query Limits

### Log Groups

A single request can query up to:

> **20 log groups**

### Query Timeout

Queries **time out after 15 minutes** if they have not completed.

### Query Results

Query results are available for:

> **7 days**

# 🧠 CloudWatch Logs — Important Difference

| Feature           | Purpose                                                       |
| ----------------- | ------------------------------------------------------------- |
| **Log Stream**    | Sequence of log events from a monitored source                |
| **Log Event**     | Single event in a log                                         |
| **Filter Events** | Basic filtering of log events                                 |
| **Logs Insights** | Interactive search and advanced analysis of logs              |
| **Athena**        | Can analyze CloudTrail/other data after logs are stored in S3 |

### Easy memory trick

> **Filter Events → Simple filtering**
> **Logs Insights → Advanced interactive analysis**
> **Athena → Analyze data in S3**

* **CloudWatch Logs Insights** → interactively search and analyze CloudWatch Logs.
* Supports **all types of logs**.
* Uses its own **Query Syntax**.
