## AWS Pricing Calculator — Notes

The **AWS Pricing Calculator** is a **free cost-estimation tool** that you can use through a **web browser** to estimate the cost of AWS services.

### 1. Key points

* **Free** to use.
* Works through a **web browser**.
* You **do not need an AWS account** to create an estimate.
* Supports **100+ AWS services** for cost estimation.
* You can configure services based on your expected requirements.
* The final estimate can be **exported to CSV**.

---

### 2. Why use AWS Pricing Calculator?

A company can use it to estimate how much an AWS environment might cost **before actually deploying it**.

For example, if a company wants to migrate from on-premises infrastructure to AWS, it can:

**Existing on-premises cost**
↓
**Estimate AWS cost using Pricing Calculator**
↓
**Compare the two**
↓
**Make a migration/cost decision**

This connects directly with the **TCO** concept you just studied.

---

### 3. Example

Suppose you're planning an application with:

* EC2
* RDS
* Storage
* Networking
* AWS Support

You can add these services to the calculator and configure their expected usage.

The calculator can then provide an estimate such as:

**Monthly cost → $4,751.53**

**12-month estimated cost → $57,018.36**

The exact numbers obviously depend on the configuration.

---

### 4. Pricing Calculator vs TCO

This distinction is useful for the exam:

**AWS Pricing Calculator**

> "How much might my AWS services cost?"

**TCO**

> "How much does my entire existing solution cost compared with the AWS solution?"

So the Pricing Calculator can be **used as part of a TCO analysis** when comparing existing infrastructure with AWS.
