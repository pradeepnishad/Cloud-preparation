# What is Cloud Computing?

### Simple Definition

**Cloud computing is the on-demand delivery of IT resources over the Internet with pay-as-you-go pricing.**

In simple words, instead of **buying and maintaining your own IT infrastructure**, you can **rent computing resources from a cloud provider whenever you need them** and pay only for what you use.

---

## AWS Definition

> **Cloud computing is the on-demand delivery of IT resources over the Internet with pay-as-you-go pricing.**

Instead of buying, owning, and maintaining **physical data centers and servers**, you can access technology services such as:

* **Computing power**
* **Storage**
* **Databases**
* **Networking**
* **Security**
* **Analytics**
* **Machine Learning**
* **Application services**

These resources are provided by cloud providers such as **Amazon Web Services (AWS)**.

---

## Breaking Down the Definition

### 1. On-demand

**On-demand** means you can get resources **whenever you need them**, without waiting for someone to physically install or configure hardware.

For example:

You need a server for a new application.

**Traditional approach:**

```text
Buy Server
     ↓
Wait for Delivery
     ↓
Install Hardware
     ↓
Configure Server
     ↓
Start Application
```

**Cloud approach:**

```text
Open AWS
    ↓
Create a Server
    ↓
Configure it
    ↓
Start Application
```

You can usually create resources within minutes.

---

### 2. IT Resources

IT resources are the technology components required to run applications and systems.

Examples:

```text
IT Resources
│
├── Compute
│   └── Virtual Servers
│
├── Storage
│   └── Files / Objects / Disks
│
├── Databases
│   └── SQL / NoSQL
│
├── Networking
│   └── VPC / Load Balancer
│
└── Security
    └── IAM / Encryption
```

For example, **Amazon EC2** provides computing capacity, while **Amazon S3** provides object storage.

---

### 3. Over the Internet

Cloud resources are accessed through a network, typically the **Internet**.

For example:

```text
Your Computer
      │
      │ Internet
      ↓
   AWS Cloud
      │
      ├── EC2
      ├── S3
      ├── RDS
      └── Other Services
```

You don't need the physical AWS server sitting in your office. The infrastructure is located in AWS data centers.

---

### 4. Pay-as-you-go Pricing

**Pay-as-you-go** means you generally pay based on how much of a resource you consume.

For example, instead of purchasing a physical server for ₹2,00,000:

```text
Traditional:
Buy Server → ₹2,00,000
```

With cloud:

```text
Cloud:
Rent Resources → Pay based on usage
```

This allows organizations to avoid large upfront infrastructure costs.

## Traditional IT vs Cloud Computing

### Traditional IT

```text
Company
  │
  ├── Buy Servers
  ├── Buy Storage
  ├── Build Data Center
  ├── Maintain Hardware
  ├── Pay Electricity
  └── Hire Infrastructure Staff
```

The company is responsible for much of the infrastructure.

### Cloud Computing

```text
Company
    │
    │ Internet
    ↓
Cloud Provider
    │
    ├── Servers
    ├── Storage
    ├── Networking
    ├── Data Centers
    └── Physical Infrastructure
```

The cloud provider manages the underlying physical infrastructure, while the customer uses the services they need.

---

## Example

Suppose you want to build a website.

You might need:

```text
Website
  │
  ├── EC2 → Compute
  │
  ├── S3 → Storage
  │
  └── RDS → Database
```

Instead of purchasing three different physical systems, you can provision these services from AWS.

If your website suddenly becomes popular:

```text
Normal Traffic
     ↓
Few Resources

High Traffic
     ↓
Increase Resources
```

You can scale your infrastructure according to demand.

## Key Characteristics of Cloud Computing

Remember these important points:

| Concept                   | Meaning                                                 |
| ------------------------- | ------------------------------------------------------- |
| **On-demand**             | Resources are available whenever required               |
| **Internet**              | Resources are accessed through a network/Internet       |
| **Pay-as-you-go**         | Pay according to usage                                  |
| **Scalability**           | Increase or decrease resources as needed                |
| **Cloud Provider**        | Company that provides cloud infrastructure/services     |
| **No physical ownership** | You generally don't need to own the underlying hardware |

## NIST Definition of Cloud Computing

The definition in the image is from **NIST (National Institute of Standards and Technology)**.

> **Cloud computing is a model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources that can be rapidly provisioned and released with minimal management effort or service provider interaction.**

### Breaking it down

**1. Ubiquitous access**
Cloud resources can be accessed **from almost anywhere** through a network, provided you have the required connectivity and access.

**2. Convenient, on-demand access**
Resources are available **when you need them** without requiring lengthy hardware procurement or setup.

**3. Shared pool of resources**
The cloud provider maintains a large pool of resources such as:

```text
Computing Resources
│
├── CPU
├── Memory
├── Storage
├── Network
└── Databases
```

These resources are shared among multiple customers while being logically isolated.

**4. Rapidly provisioned and released**
Resources can be **quickly created, scaled up, scaled down, or removed**.

Example:

```text
High Traffic
     ↓
Add Resources
     ↓
Handle Traffic
     ↓
Traffic Decreases
     ↓
Release Resources
```

**5. Minimal management effort**
The customer doesn't need to manually manage the underlying physical infrastructure. Much of the infrastructure management is handled by the cloud provider.

# NIST Cloud Computing Model

According to NIST, the cloud model consists of:

```text
                 CLOUD COMPUTING
                        │
        ┌───────────────┼───────────────┐
        ↓               ↓               ↓
  5 Essential      3 Service        4 Deployment
  Characteristics    Models           Models
```

### 5 Essential Characteristics

1. **On-demand self-service**
2. **Broad network access**
3. **Resource pooling**
4. **Rapid elasticity**
5. **Measured service**

### 3 Service Models

1. **IaaS** — Infrastructure as a Service
2. **PaaS** — Platform as a Service
3. **SaaS** — Software as a Service

### 4 Deployment Models

1. **Public Cloud**
2. **Private Cloud**
3. **Community Cloud**
4. **Hybrid Cloud**

### Exam Point

For your exam, remember the structure:

**NIST Cloud Computing = 5 + 3 + 4**

```text
5 Characteristics
        +
3 Service Models
        +
4 Deployment Models
```

This **5–3–4 framework** is important for foundational-level cloud exams.
