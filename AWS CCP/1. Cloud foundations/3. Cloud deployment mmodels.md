# Cloud Deployment Models

There are **4 official NIST deployment models**:

1. **Private Cloud**
2. **Community Cloud**
3. **Public Cloud**
4. **Hybrid Cloud**

> **Important:** **Multi-cloud is not one of the 4 NIST deployment models.** It is a modern cloud strategy where an organization uses services from **multiple cloud providers**.

---

## 1. Private Cloud

> **The cloud infrastructure is provisioned for exclusive use by a single organization comprising multiple consumers. It may be owned, managed, and operated by the organization, a third party, or some combination of them, and it may exist on or off premises.**

### Explanation

A **private cloud** is dedicated to **one organization**. Other unrelated organizations do not share the cloud infrastructure.

```text
              Private Cloud
                   │
             Organization
                   │
        ┌──────────┼──────────┐
        ↓          ↓          ↓
     Team A      Team B      Team C
```

The infrastructure can be:

* Owned by the organization
* Managed by the organization
* Managed by a third party
* Located inside the organization's premises
* Located outside the organization's premises

### Example

A large bank may maintain a private cloud to run its internal banking applications and databases.

### Key Point

**Private Cloud = Exclusive use by ONE organization.**

---

# 2. Community Cloud

> **The cloud infrastructure is provisioned for exclusive use by a specific community of consumers from organizations that have shared concerns.**

### Explanation

A **community cloud** is shared by **multiple organizations that have common requirements or concerns**.

For example, organizations may have similar:

* Security requirements
* Compliance requirements
* Privacy requirements
* Regulatory requirements
* Business objectives

```text
             Community Cloud
                    │
       ┌────────────┼────────────┐
       ↓            ↓            ↓
   Organization A  Organization B  Organization C
```

Unlike a public cloud, it isn't intended for everyone.

### Example

Several government organizations with similar security and compliance requirements could share a community cloud.

### Key Point

**Community Cloud = Exclusive use by a specific COMMUNITY of organizations with shared concerns.**

---

# 3. Public Cloud

### Definition

> **The cloud infrastructure is provisioned for open use by the general public. It may be owned, managed, and operated by a business, academic, or government organization, or some combination of them.**

### Explanation

A **public cloud** is cloud infrastructure that is available to the **general public or a broad range of customers**.

Cloud providers build and operate large-scale infrastructure and allow many customers to use their services.

Examples of public cloud providers include:

* AWS
* Microsoft Azure
* Google Cloud

```text
                 Public Cloud
                      │
        ┌─────────────┼─────────────┐
        ↓             ↓             ↓
    Customer A    Customer B    Customer C
```

The customers share the provider's underlying infrastructure, while their resources and data are logically isolated.

### Example

You create an **EC2 instance on AWS** to host your website. You are using a public cloud.

### Key Point

**Public Cloud = Cloud infrastructure available for use by the general public.**

---

# 4. Hybrid Cloud

### Definition

> **The cloud infrastructure is a composition of two or more distinct cloud infrastructures (private, community, or public) that remain unique entities but are connected by technology that enables data and application portability.**

### Explanation

A **hybrid cloud combines different cloud environments**, typically a **private cloud and a public cloud**, allowing them to work together.

```text
        Private Cloud
             │
             │ Connection
             ↓
         Public Cloud
```

### Example

A company keeps sensitive customer information in its private cloud but uses AWS for additional computing capacity when demand increases.

```text
             Company
                │
       ┌────────┴────────┐
       ↓                 ↓
 Private Cloud      Public Cloud
 Sensitive Data     Extra Compute
```

### Key Point

**Hybrid Cloud = Combination of two or more different cloud infrastructures that are connected and can work together.**

---

# 5. Multi-Cloud

> **Multi-cloud means using cloud services from two or more different cloud providers.**

This is **not one of the four NIST deployment models**.

For example:

```text
             Organization
                  │
       ┌──────────┼──────────┐
       ↓          ↓          ↓
      AWS       Azure      Google Cloud
```

An organization might use:

* **AWS** → Compute
* **Azure** → Microsoft-related workloads
* **Google Cloud** → Data/ML services

### Why use Multi-Cloud?

Organizations may choose multiple providers to:

* Avoid depending completely on one provider
* Use specialized services from different providers
* Improve availability
* Meet geographic or regulatory requirements
* Choose the best price/performance for different workloads

### Multi-Cloud vs Hybrid Cloud

This distinction is **very important**:

|                        | Hybrid Cloud                                                  | Multi-Cloud              |
| ---------------------- | ------------------------------------------------------------- | ------------------------ |
| Meaning                | Combination of different cloud environments                   | Multiple cloud providers |
| Providers              | Can involve one or more providers                             | **2+ providers**         |
| Example                | Private Cloud + AWS                                           | AWS + Azure              |
| Must be connected?     | **Yes, integration/portability is part of NIST's definition** | Not necessarily          |
| NIST deployment model? | ✅ Yes                                                         | ❌ No                     |

### Easy way to remember

```text
PRIVATE
   ↓
ONE organization

COMMUNITY
   ↓
GROUP of organizations with shared concerns

PUBLIC
   ↓
GENERAL public

HYBRID
   ↓
COMBINATION of different cloud infrastructures

MULTI-CLOUD
   ↓
MULTIPLE cloud PROVIDERS
```

**Exam tip:** If the question specifically asks for **NIST's 4 deployment models**, answer **Private, Community, Public, and Hybrid**. Do **not** include Multi-cloud.
