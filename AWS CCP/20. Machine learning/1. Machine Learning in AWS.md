# 1. ML and AI and Big Data

## What is Artificial Intelligence (AI)?

**Artificial Intelligence (AI)** is the field of creating systems that can perform tasks that normally require human intelligence.

Examples:

* Understanding language
* Recognizing images
* Making predictions
* Decision making
* Generating text/images

### AI → Broadest concept

```text
Artificial Intelligence
        │
        └── Machine Learning
                │
                └── Deep Learning
                        │
                        └── Generative AI
```

---

## What is Machine Learning (ML)?

**Machine Learning** allows computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every situation.

### Example

Give a model thousands of examples of spam and non-spam emails.

The model learns patterns and predicts:

```text
New Email → ML Model → Spam / Not Spam
```

---

## What is Big Data?

**Big Data** refers to extremely large and complex datasets that traditional systems may struggle to process.

Common characteristics:

* **Volume** → huge amount of data
* **Velocity** → data generated rapidly
* **Variety** → structured, semi-structured and unstructured data
* **Veracity** → reliability/quality of data
* **Value** → useful information extracted from data

### Simple difference

| Technology | Main purpose                  |
| ---------- | ----------------------------- |
| AI         | Simulate intelligent behavior |
| ML         | Learn patterns from data      |
| Big Data   | Store/process huge datasets   |

# 13. What is a GPU?

## GPU = Graphics Processing Unit

A GPU is a processor designed to perform a large number of operations **in parallel**.

Originally designed primarily for graphics, GPUs are now heavily used for:

* Machine Learning
* Deep Learning
* AI
* Scientific computing
* 3D rendering

### CPU vs GPU

**CPU:**

```text
Few powerful cores
        ↓
General-purpose processing
```

**GPU:**

```text
Many processing cores
        ↓
Massively parallel processing
```

### Why GPUs are useful for AI

ML workloads often perform huge numbers of mathematical operations simultaneously.

Therefore:

> **GPU → Parallel computation → Faster AI/ML workloads**

# 15. Introduction to Athena

## Amazon Athena

**Amazon Athena** is a **serverless interactive query service**.

It allows you to query data stored in services such as **Amazon S3 using SQL**.

### Example

```text
Data
 ↓
Amazon S3
 ↓
Athena
 ↓
SQL Query
 ↓
Results
```

### Important characteristics

* Serverless
* Uses SQL
* Works with data in S3
* No infrastructure to manage
* Useful for ad-hoc analysis

### Example query

```sql
SELECT *
FROM logs
WHERE status = 'ERROR';
```

### ⭐ Exam point

> **Athena = SQL query service for data stored in S3**

# 16. Introduction to AWS Glue

## What is AWS Glue?

**AWS Glue** is a **serverless data integration and ETL service**.

ETL means:

> **Extract → Transform → Load**

### Glue can help you:

* Discover data
* Catalog data
* Transform data
* Prepare data for analytics
* Move data between sources

### Basic workflow

```text
Data Source
    ↓
Extract
    ↓
Transform
    ↓
Load
    ↓
Data Lake / Data Warehouse
```

---

## AWS Glue Data Catalog

The **Glue Data Catalog** stores metadata about your data.

It can contain information such as:

* Tables
* Columns
* Data types
* Locations
* Schemas

### Example

Your actual data:

```text
S3
 └── sales/
      ├── 2025.csv
      └── 2026.csv
```

Glue Data Catalog can maintain metadata describing that data.

Athena can then use the catalog to query it.
