## Elastic IP (EIP)

An **Elastic IP address** is a **static public IPv4 address** that you can allocate to your AWS account and associate with an EC2 instance.

Normally, an EC2 public IP can change when you **stop and start** the instance.

### Without Elastic IP

```text
EC2 starts
   ↓
Public IP: 13.234.10.20

Stop → Start
   ↓
Public IP: 3.110.55.80
```

So if you were connecting using:

```bash
ssh -i mykey.pem ubuntu@13.234.10.20
```

that IP may no longer work after a stop/start.

### With Elastic IP

```text
Elastic IP
13.234.10.20
     │
     ↓
    EC2
```

The address remains associated with your AWS account until you release it.

---

## How to create one

Go to:

```text
AWS Console
 → EC2
 → Elastic IPs
 → Allocate Elastic IP address
```

Then:

```text
Allocate
   ↓
Select Elastic IP
   ↓
Actions
   ↓
Associate Elastic IP
   ↓
Select EC2 instance
   ↓
Associate
```

Now you can SSH using:

```bash
ssh -i mykey.pem ubuntu@<ELASTIC-IP>
```

---

## Important: Elastic IP ≠ Private IP

An EC2 instance can have both:

```text
Internet
   │
   ↓
Elastic IP / Public IPv4
   │
   ↓
EC2
   │
   ↓
Private IP
172.31.x.x
```

The **private IP** is used inside the VPC.

The **Elastic IP** is a static public IPv4 address.

---

## ⚠️ Important cost consideration

Don't allocate Elastic IPs and leave them unused. AWS charges for public IPv4 addresses, including Elastic IP addresses, under its current public IPv4 pricing model.

For your learning account, **release the Elastic IP when you're finished**:

```text
EC2
 → Elastic IPs
 → Select IP
 → Actions
 → Release Elastic IP address
```

Also remember: **disassociating** an Elastic IP is not the same as **releasing** it. If you no longer need it, release it.
