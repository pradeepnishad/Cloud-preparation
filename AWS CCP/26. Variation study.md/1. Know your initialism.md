# 🧠 AWS Initialisms — Exam Cheat Sheet

## 🔐 Security & Identity

| Acronym | Full form | Remember it as |
|---|---|---|
| **IAM** | Identity and Access Management | 👤 Users, permissions, access |
| **PoLP** | Principle of Least Privilege | 🔒 Minimum permissions necessary |
| **ACM** | AWS Certificate Manager | 📜 SSL/TLS certificates |
| **WAF** | Web Application Firewall | 🌐 Web application protection |

---

## 💾 Storage & Databases

| Acronym | Full form | Remember it as |
|---|---|---|
| **S3** | Simple Storage Service | 🪣 Object storage |
| **EBS** | Elastic Block Store | 💿 Block storage for EC2 |
| **EFS** | Elastic File System | 📁 Shared file storage |
| **RDS** | Relational Database Service | 🗄️ Managed relational DB |
| **ECR** | Elastic Container Registry | 📦 Container images |

---

## 🌐 Networking

| Acronym | Full form | Remember it as |
|---|---|---|
| **VPC** | Virtual Private Cloud | 🌐 Your private AWS network |
| **VPN** | Virtual Private Network | 🔐 Secure network tunnel |
| **ELB** | Elastic Load Balancer | ⚖️ Distributes traffic |
| **ALB** | Application Load Balancer | 🌐 HTTP/HTTPS / Layer 7 |
| **NLB** | Network Load Balancer | ⚡ High-performance network traffic |
| **GWLB** | Gateway Load Balancer | 🔥 Network virtual appliances |
| **CLB** | Classic Load Balancer | 🕰️ Older load balancer |

### ⭐ Remember

```text
ELB
├── ALB → Application
├── NLB → Network
└── GWLB → Gateway
```

# 🖥️ Compute & Containers

| Acronym | Full form | Remember it as |
|---|---|---|
| **EC2** | Elastic Compute Cloud | 🖥️ Virtual servers |
| **ASG** | Auto Scaling Group | 📈 Automatically adjusts EC2 capacity |
| **ECS** | Elastic Container Service | 🐳 Container orchestration |
| **EKS** | Elastic Kubernetes Service | ☸️ Managed Kubernetes |
| **ECR** | Elastic Container Registry | 📦 Store container images |
| **EB** | Elastic Beanstalk | 🚀 Deploy applications easily |
| **EMR** | Elastic MapReduce | 📊 Big data processing |

### Important distinction

**ECS ≠ EKS**

- **ECS** → AWS container orchestration service
- **EKS** → Managed **Kubernetes**

# 🔥 HIGH-PRIORITY FOR CLF-C02

If you're short on time, prioritize these:

### Tier 1 — MUST KNOW

**IAM, S3, EC2, VPC, RDS, SQS, SNS, ELB, ALB, NLB, EBS, EFS, ECS, EKS, ASG, VPN, WAF, KMS, ACM, RAM**

### Tier 2 — Know the meaning

**ECR, CloudFormation (CFN), SSM, EMR, EB, RI, IoT, TAM, MSK**

### 🧠 One-minute revision

```text
IAM  → Identity/access
S3   → Object storage
EC2  → Virtual server
VPC  → Private network
RDS  → Relational database
EBS  → Block storage
EFS  → File storage

ALB  → Application traffic
NLB  → Network traffic
ASG  → Auto-scale EC2

SQS  → Queue
SNS  → Notifications
SES  → Email

ECS  → Containers
EKS  → Kubernetes
ECR  → Container images

WAF  → Web protection
VPN  → Secure tunnel
ACM  → Certificates
RAM  → Resource sharing
CFN  → Infrastructure as Code
SSM  → Systems management
RI   → Reserved pricing
```

**Exam tip:** Don't just memorize the expansion. For CLF-C02, knowing **what the service does** is much more valuable than knowing the full name alone.
