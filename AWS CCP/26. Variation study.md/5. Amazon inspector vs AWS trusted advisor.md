# 🔍 Amazon Inspector vs Trusted Advisor

The slide's main idea:

> **Both are security-related tools that perform audits, but they look at your AWS environment differently.**

---

## 1. 🔎 Amazon Inspector

### What does it inspect?

According to the slide, Inspector audits a **selected/specific EC2 instance**.

Think:

```text
AWS Account
   │
   ├── EC2 #1
   ├── EC2 #2  ← Inspector assessment
   ├── EC2 #3
   └── EC2 #4
```

It performs a large number of **security checks** against the selected EC2 instance.

The slide gives the example of **699 checks**.

### What does it produce?

Inspector generates a **report** containing the security findings from those checks.

So the mental model is:

> **Inspector = Deep security assessment of a specific workload/EC2 instance.**

---

# 🛡️ 2. AWS Trusted Advisor

Trusted Advisor has a **broader view**.

Instead of focusing on one EC2 instance, it provides recommendations across **multiple AWS services**.

Think:

```text
             Trusted Advisor
                   ↓
       ┌───────────┼───────────┐
       ↓           ↓           ↓
      EC2          S3         IAM
       ↓           ↓           ↓
   Recommendations / Best Practices
```

The slide calls this a:

> **Holistic view**

Meaning it looks at your AWS environment more broadly and provides recommendations.

### Examples from the slide:

It could tell you:

- Some security groups have open ports.
- You should enable MFA on the root account.

So Trusted Advisor is more like:

> **"Here are things you should improve across your AWS environment."**

---

# 🔥 Main Difference

| | **Amazon Inspector** | **Trusted Advisor** |
|---|---|---|
| Main focus | Security assessment | Recommendations / best practices |
| Scope in this slide | Specific EC2 instance | Multiple AWS services |
| Approach | Detailed security checks | Holistic recommendations |
| Example | Hundreds of security checks | Open ports, root MFA recommendation |
| Report | Generates a report | Doesn't generate the PDF report described here |

## ⚠️ One thing to be careful about

The slide is giving you a **simplified exam-oriented comparison**. Don't memorize it as:

> "Inspector ONLY works on one EC2."

The key exam distinction is the **scope and purpose**:

**Inspector → automated vulnerability/security assessment**

**Trusted Advisor → AWS environment recommendations and best practices**

### 🧠 Final memory line

> 🔍 **Inspector = "Inspect this workload."**  
> 🛡️ **Trusted Advisor = "Advise me about my AWS environment."**
