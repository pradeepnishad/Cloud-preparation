# ☁️ AWS CloudWatch Logs — Log Streams & Log Events

## 1. CloudWatch Log Streams

### What is a Log Stream?

A **Log Stream** represents a:

> **Sequence of events from an application or instance being monitored.**

Think of it as a continuous stream of log activity coming from a particular source.

### Creating Log Streams

* Log streams **can be created manually**.
* Generally, they are **automatically created by the AWS service** you are using.

---

## 2. How Log Streams Are Named

The naming of log streams can depend on the AWS service generating the logs.

### AWS Lambda

For a Lambda function, log streams are named based on the **running instance**.

Lambda frequently runs on new instances, so the log streams contain **timestamps**.

```text
Lambda Function
      ↓
Running Instance
      ↓
Log Stream
      ↓
Log Events
```

---

### EC2 Application Logs

For application logs running on **EC2**, log streams are named after the:

> **Running instance's Instance ID**

Example:

```text
EC2 Instance
   ↓
Instance ID
   ↓
Log Stream
```

---

### AWS Glue

For **AWS Glue**, log streams are named after the:

> **Glue Jobs**

So:

```text
Glue Job
   ↓
Log Stream
```

---

# 📝 3. Log Events

### What is a Log Event?

A **Log Event** represents a:

> **Single event in a log file.**

Log events can be viewed **inside a Log Stream**.

```text
Log Group
    ↓
Log Stream
    ↓
Log Events
```

### Example

A Lambda log stream can contain events such as:

```text
START RequestId
records_size
failed_put_count
END RequestId
REPORT RequestId
```

Each of these represents an individual **log event**.

---

# 🔎 4. Filtering Log Events

CloudWatch Logs allows you to use **Filter events** to find specific logs.

You can filter logs using:

* Simple matching
* Pattern matching syntax

Example:

```text
Log Events
     ↓
Filter Events
     ↓
Search specific pattern
     ↓
Relevant log events
```

This is useful when a log stream contains a large number of events and you need to find specific information.

---

# 🧠 Important Difference

| Term           | Meaning                                                      |
| -------------- | ------------------------------------------------------------ |
| **Log Group**  | Container for related log streams                            |
| **Log Stream** | Sequence of log events from a monitored application/instance |
| **Log Event**  | A single event/entry in a log                                |

### Easy way to remember:

> **Group → Stream → Event**

```text
📁 Log Group
   │
   ├── 📜 Log Stream 1
   │      ├── Event
   │      ├── Event
   │      └── Event
   │
   └── 📜 Log Stream 2
          ├── Event
          ├── Event
          └── Event
```

### 🎯 Exam Focus

**Log Stream** = sequence of events from an application/instance being monitored.

**Log Event** = single event in a log file.

**Log Events are viewed within a Log Stream.**

**Filter Events** = filter/search log events using simple or pattern matching syntax.
