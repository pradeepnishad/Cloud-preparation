# ☁️ AWS CloudWatch Alarms

## 1. What is a CloudWatch Alarm?

A **CloudWatch Alarm** monitors a **CloudWatch Metric** based on a **defined threshold**.

> **Metric → Threshold → Alarm State → Action**

Example:

If `NetworkIn > 300` for a defined period, the alarm can change its state.

---

## 2. How CloudWatch Alarm Works

1. CloudWatch monitors a **metric**
2. The metric is compared against a **defined threshold**
3. If the threshold is breached, the alarm **changes state**
4. When the state changes, you can configure an **action to trigger**

### Example

```text
EC2 NetworkIn
      ↓
Check threshold
      ↓
NetworkIn > 300
      ↓
Alarm State changes
      ↓
Trigger Action
```

---

# 🚦 3. CloudWatch Alarm States

There are **3 important states**:

### 🟢 OK

The metric or expression is **within the defined threshold**.

```text
Metric = Normal
State  = OK
```

---

### 🔴 ALARM

The metric or expression is **outside the defined threshold**.

```text
Metric = Threshold breached
State  = ALARM
```

Example:

```text
Threshold: NetworkIn > 300

NetworkIn = 350
        ↓
ALARM
```

---

### 🔵 INSUFFICIENT_DATA

There isn't enough data available to determine the alarm state.

This can happen when:

* The alarm has **just started**
* The metric is **not available**
* There is **not enough data**

```text
Not enough information
        ↓
INSUFFICIENT_DATA
```

---

# ⚡ 4. Actions Triggered by CloudWatch Alarms

When an alarm changes state, you can define actions that should be triggered.

The slide gives these examples:

### 📢 Notification

Send a notification when the alarm state changes.

### 📈 Auto Scaling Group

Trigger an **Auto Scaling** action.

### 🖥️ EC2 Action

Trigger an action on an **EC2 instance**.

# 🎯 Exam Notes

| Term                   | Remember                                     |
| ---------------------- | -------------------------------------------- |
| **CloudWatch Alarm**   | Monitors a CloudWatch Metric                 |
| **Threshold**          | Defines the condition being monitored        |
| **OK**                 | Metric is within threshold                   |
| **ALARM**              | Metric is outside threshold                  |
| **INSUFFICIENT_DATA**  | Not enough data to determine state           |
| **Alarm state change** | Can trigger an action                        |
| **Actions**            | Notification, Auto Scaling Group, EC2 Action |

### 🔥 Most important

> **OK = Within threshold**
> **ALARM = Outside threshold**
> **INSUFFICIENT_DATA = Not enough data**
