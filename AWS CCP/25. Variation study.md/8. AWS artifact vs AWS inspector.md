# 🔐 AWS Artifact vs Amazon Inspector

## 1. AWS Artifact — "Can I trust AWS?"

**AWS Artifact** provides access to AWS's **compliance and security documentation**.

The slide's question is:

> **"Why should an enterprise trust AWS?"**

It provides reports/documents related to **global compliance frameworks**, such as:

- **SOC** — Service Organization Control
- **PCI** — Payment Card Industry

### Think of it like:

```text
AWS
 │
 ├── SOC reports
 ├── PCI reports
 ├── Compliance documents
 └── Security documentation
          ↓
     Enterprise
     verifies AWS
     compliance
```

So Artifact is mainly about **AWS's own compliance** and giving customers evidence/documentation.

### 🧠 Remember:

**Artifact = AWS Compliance Documents**

---

# 2. Amazon Inspector — "Is my EC2 secure?"

Amazon Inspector is a **security assessment/vulnerability scanning service**.

The slide asks:

> **"How do we know this EC2 instance is secure? Prove it?"**

It analyzes your **EC2 instance** and produces a report showing which security checks passed.

The key phrase from the slide:

> **"Audit tool for security of EC2 instances"**

Think:

```text
Your EC2
   ↓
Amazon Inspector
   ↓
Security checks
   ↓
Findings / Report
   ↓
Is the EC2 secure?
```

---

# ⚔️ The Important Difference

| | **AWS Artifact** | **Amazon Inspector** |
|---|---|---|
| Main purpose | Compliance documentation | Security assessment |
| Focus | **AWS compliance** | **Your workloads/resources** |
| Question | "Can I trust AWS?" | "Is my EC2 secure?" |
| Provides | Compliance reports/documents | Security findings/assessment |
| Example | SOC, PCI | EC2 security/vulnerability checks |
| Memory | 📄 **Compliance** | 🔍 **Security scanning** |
