# AWS Resource Groups

## 1. Definition

**Resource Groups** are a collection of AWS resources that **share one or more tags**.

In simple terms:

> **Resource Group = a group of AWS resources organized using tags.**

For example, suppose you have:

```text
EC2-1 → Project = ECommerce
EC2-2 → Project = ECommerce
RDS-1 → Project = ECommerce
S3-1  → Project = ECommerce
```

You can group these resources based on the common tag:

```text
Project = ECommerce
```

---

## 2. Why Use Resource Groups?

Resource Groups help you **organize and consolidate information** about resources based on your project and the resources you use.

Instead of looking at individual resources separately, you can view related resources together.

---

## 3. What Can Resource Groups Display?

According to the source, Resource Groups can display details about the grouped resources based on:

### Metrics

You can view relevant resource metrics.

### Alarms

You can view alarms associated with resources in the group.

### Configuration Settings

You can view configuration-related information for the resources.

So:

> **Resource Group → Resources → Metrics + Alarms + Configuration**

---

## 4. How Does It Work?

Resource Groups use **tags** to determine which resources belong to a group.

For example:

```text
Tag:
Environment = Production
```

Resources:

```text
EC2-1 → Environment = Production
EC2-2 → Environment = Production
RDS-1 → Environment = Production
```

These resources can be included in a Resource Group based on that tag.

You can also modify the settings of a Resource Group at any time to change **which resources appear** in the group.

---

## 5. Where Can You Access Resource Groups?

The source shows Resource Groups appearing in:

* **AWS Management Console**
* **AWS Systems Manager**

The important exam concept is that Resource Groups help organize resources so that you can manage/view related resources together.

---

## 6. Resource Groups vs Tags

This distinction is important.

| Tags                                                   | Resource Groups                                |
| ------------------------------------------------------ | ---------------------------------------------- |
| Key-value metadata                                     | Collection of resources                        |
| Applied to resources                                   | Groups resources based on tags                 |
| Example: `Project = ECommerce`                         | Group all ECommerce resources                  |
| Used for organization, cost tracking, automation, etc. | Used to view/manage related resources together |

### Think of it like this:

```text
TAG
 ↓
Project = ECommerce
 ↓
RESOURCE GROUP
 ↓
EC2 + RDS + S3 + Lambda
```

**Tag = label**

**Resource Group = collection based on labels**

---

# 7. Scenario-Based Example

Imagine you're running a production application:

```text
EC2 Web Server
EC2 App Server
RDS Database
Lambda Functions
```

You tag them:

```text
Project = ShoppingApp
Environment = Production
```

Now you can create a Resource Group based on:

```text
Project = ShoppingApp
Environment = Production
```

The Resource Group brings those related resources together, allowing you to view relevant:

* Metrics
* Alarms
* Configuration settings

If you later change the group's settings, the resources displayed in that group can change.
