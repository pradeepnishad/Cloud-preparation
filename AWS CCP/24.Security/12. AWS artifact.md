# 📄 AWS Artifact

## 1. WHAT is AWS Artifact?

**AWS Artifact** is a **self-service portal** that provides **on-demand access to AWS compliance reports**.

In simple words:

> **AWS Artifact = Place where you can access AWS compliance documents and reports.**

These reports help organizations understand and demonstrate AWS's compliance with various security and regulatory standards.

### Examples shown in the material:
- **SOC**
- **ISO 27001**
- **PCI**
- **C5**
- **IRAP**
- **FedRAMP**

---

# 2. WHERE do you use AWS Artifact?

AWS Artifact is used when you need **AWS compliance documentation**.

For example, an organization may need to verify:

> "Does AWS meet the security/compliance requirements relevant to our business?"

Instead of searching around for individual documents, you can access the relevant reports through **AWS Artifact**.

### Typical use cases

- Compliance audits
- Security assessments
- Regulatory requirements
- Customer/vendor compliance reviews
- Internal governance
- Understanding AWS compliance certifications

---

# 3. HOW does AWS Artifact work?

AWS Artifact is a **self-service portal**, meaning you can access the available reports yourself.

### Basic flow:

```text
AWS Artifact
     ↓
Choose a compliance report
     ↓
View report/document
     ↓
Download the report
     ↓
Use it for compliance / audit purposes
```

The material shows reports being selected and then made available as downloadable documents.

# 5. 📥 Downloading Reports

The material demonstrates that you can:

1. **Choose a report**
2. **View the report**
3. Access it as a **PDF**
4. Download the associated **Excel/XLSX** information where available

So AWS Artifact isn't an AWS service for configuring infrastructure.

It is primarily a **compliance-documentation portal**.

---

# 6. AWS Artifact vs AWS Audit Manager

This is a useful distinction:

| AWS Artifact | AWS Audit Manager |
|---|---|
| Provides access to **AWS compliance reports** | Helps you **collect evidence for your own audits** |
| Focuses on AWS's compliance documentation | Focuses on your organization's compliance/audit process |
| Self-service portal | Audit evidence collection/management |

### 🧠 Easy way to remember

> **Artifact = AWS's compliance reports**

> **Audit Manager = Your audit evidence**
