

# 🛡️ AWS Shield

### What is AWS Shield?

**AWS Shield is a managed DDoS protection service** that protects applications running on AWS from **Distributed Denial-of-Service (DDoS) attacks**.

Think of it like a **security guard in front of your application**:

```text
                    Internet
                       │
              🚨 Attack / Traffic
                       │
                       ▼
                 AWS Shield
                       │
                 Legitimate
                   Traffic
                       │
                       ▼
                 Your Server
```

The important word is **managed**.

You don't have to build your own DDoS protection infrastructure. AWS operates and manages Shield for you.

---

# 🌊 First: What is a DDoS attack?

A **DDoS (Distributed Denial-of-Service)** attack attempts to overwhelm a service with a huge amount of traffic or requests.

For example:

```text
Attacker
   │
   ├──── Bot ──────┐
   ├──── Bot ──────┤
   ├──── Bot ──────┤
   ├──── Bot ──────┤
   └──── Bot ──────┘
                   │
                   ▼
              Your Website
```

The goal is to consume resources such as:

- Network bandwidth
- Server capacity
- Application resources
- Connection capacity

So legitimate users may experience slow responses or become unable to access the application.

# 🧠 What does "Layer 3, 4 and 7" mean?

This is very important.

Remember the simplified OSI layers:

```text
Layer 7 → Application
Layer 4 → Transport
Layer 3 → Network
```

### Layer 3 — Network

Attacks targeting network-level traffic.

Examples include attacks involving large volumes of IP traffic.

### Layer 4 — Transport

Targets protocols such as:

- TCP
- UDP

The goal can be to overwhelm connections or transport-layer resources.

### Layer 7 — Application

Targets the actual application.

For example:

```text
GET /login
GET /products
POST /api/login
```

An attacker may generate huge numbers of legitimate-looking application requests.

# 🔥 Shield + WAF

The bottom of your second Shield slide is also important:

> Both plans integrate with **AWS WAF** to provide Layer 7 protection.

Think of the difference like this:

### AWS Shield

🛡️ **DDoS protection**

### AWS WAF

🚧 **Web application traffic filtering**

Together:

```text
             Internet
                │
                ▼
        ┌───────────────┐
        │ AWS Shield    │
        │ DDoS Defense  │
        └───────┬───────┘
                │
                ▼
        ┌───────────────┐
        │ AWS WAF       │
        │ Web Filtering │
        └───────┬───────┘
                │
                ▼
           Application
```

A simple way to remember:

> **Shield = DDoS protection**  
> **WAF = Web/application traffic filtering**

# 🎯 Exam-focused points

For your **AWS Cloud Practitioner**, remember these:

### 1️⃣ What is AWS Shield?

**Managed DDoS protection service.**

### 2️⃣ Shield Standard?

**Free** and automatically available with AWS services such as **Route 53 and CloudFront**.

### 3️⃣ Shield Advanced?

Provides **additional protection against larger and more sophisticated DDoS attacks** and adds features such as enhanced visibility/reporting and DDoS cost protection.

### 4️⃣ Which attack does Shield protect against?

**DDoS attacks.**

### 5️⃣ AWS Shield vs AWS WAF?

**Shield → DDoS protection**

**WAF → Web application firewall / Layer 7 traffic filtering**

### 6️⃣ Layers mentioned in your material?

**Layer 3 = Network**  
**Layer 4 = Transport**  
**Layer 7 = Application**
