# 🔐 CIA Triad — Confidentiality, Integrity & Availability

## 🔹 WHAT?

The **CIA Triad** is a foundational security model describing three core security principles:

> **Confidentiality + Integrity + Availability**

It helps organizations think about **how information should be protected throughout its lifecycle**.

The three principles also have a **trade-off relationship** — improving one aspect of security can sometimes affect another.

---

# 🔹 WHERE?

The CIA Triad applies to almost **every security environment**, including:

- ☁️ Cloud infrastructure
- 🗄️ Databases
- 💻 Applications
- 🌐 Networks
- 🔐 Encryption systems
- 👤 User access
- 🏢 Enterprise IT environments

For AWS, you can think about it whenever you're designing or securing resources.

---

# 🔹 HOW?

## 1️⃣ Confidentiality — "Who can see the data?"

### What?

**Confidentiality** means protecting data from **unauthorized viewers**.

Only authorized people or systems should be able to access sensitive information.

### How?

The slide gives encryption as an example:

- Use **cryptographic keys** to encrypt data.
- Use keys to encrypt other keys — called **envelope encryption**.

### Example

```text
Plaintext Data
      ↓
   Encryption
      ↓
Encrypted Data 🔒
      ↓
Only authorized user
with the correct key
can decrypt it
```

### 🧠 Remember

> **Confidentiality = Prevent unauthorized access to information.**

---

# 2️⃣ Integrity — "Is the data correct?"

### What?

**Integrity** means maintaining and assuring the **accuracy and completeness of data throughout its lifecycle**.

The goal is to make sure data:

- Hasn't been improperly changed
- Remains accurate
- Remains complete

### How?

The slide mentions:

- **ACID-compliant databases** for valid transactions
- **Tamper-evident / tamper-proof Hardware Security Modules (HSMs)**

### Example

Imagine a bank transaction:

```text
Account Balance: ₹50,000
       ↓
Transfer ₹10,000
       ↓
Account Balance: ₹40,000
```

The transaction should be processed correctly and the resulting data should remain accurate.

### 🧠 Remember

> **Integrity = Data remains accurate and complete.**

---

# 3️⃣ Availability — "Can I access it when needed?"

### What?

**Availability** means information and systems should be **available when needed**.

A system can be secure and have accurate data, but if users can't access it, it isn't meeting the availability requirement.

### How?

The slide mentions:

- **High Availability**
- **Mitigating DDoS attacks**
- Ensuring **decryption access**

### Example

```text
User
 ↓
Application
 ↓
Database
 ↓
Data available when needed ✅
```

If a service goes down:

```text
User
 ↓
Service ❌
 ↓
Cannot access data
```

Availability has been affected.

### 🧠 Remember

> **Availability = Information is accessible when required.**

# 🔺 THE CIA TRIAD

Think of it as three questions:

```text
                 🔐 CONFIDENTIALITY
                    "Who can see it?"
                       /\
                      /  \
                     /    \
                    /      \
                   /        \
                  /          \
                 /            \
                /______________\
      INTEGRITY                 AVAILABILITY
   "Is it correct?"          "Can I access it?"
```

### Simple memory trick:

**C → Secret**

**I → Correct**

**A → Available**

|---|---|---|
| **Confidentiality** | Who can see the data? | Prevent unauthorized access |
| **Integrity** | Is the data correct? | Maintain accuracy & completeness |
| **Availability** | Can I access it? | Make information available when needed |

# 📌 HISTORY FROM YOUR SLIDE

The slide notes that the **CIA Triad was first mentioned in a NIST publication from 1977**.

It also mentions later attempts to expand or modernize the model:

- **1998:** Six Atomic Elements of Information — including confidentiality, possession, integrity, authenticity, availability, and utility.
- **2004:** NIST Engineering Principles for Information Technology Security — **33 security principles**.
