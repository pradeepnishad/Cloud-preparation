# 🔍 AWS Inspector

## 1. WHAT is AWS Inspector?

**AWS Inspector** is a security assessment service that helps identify **security risks and vulnerabilities** in your AWS resources.

In the material, the focus is on **EC2 instances**.

It runs **security benchmarks** against specific EC2 instances to identify security issues.

### Simple definition

> **AWS Inspector = Automated security assessment that checks EC2 instances for security vulnerabilities and configuration issues.**

---

# 2. WHAT is Hardening?

**Hardening** means:

> **Eliminating as many security risks as possible.**

For virtual machines, hardening involves performing a collection of security checks against the machine.

These checks are called a **security benchmark**.

### Example

A hardened EC2 instance should have unnecessary security risks reduced through appropriate configuration and security practices.

```text
EC2 Instance
     ↓
Security Checks / Benchmark
     ↓
Find Security Risks
     ↓
Fix / Remediate Issues
     ↓
Hardened Instance
```

---

# 3. WHERE does AWS Inspector work?

The material specifically shows AWS Inspector performing assessments against **EC2 instances**.

It can perform two types of assessments:

### 🌐 Network Assessment

Looks at **network configuration** and checks for issues such as ports that may be reachable from outside the VPC.

**Inspector Agent is not required** for the network assessment shown in the material.

### 🖥️ Host Assessment

Checks the EC2 host for things such as:

- Vulnerable software
- **CVE** vulnerabilities
- Host hardening
- **CIS benchmarks**
- Security best practices

**Inspector Agent is required** for the host assessment shown in the material.

---

# 4. HOW does AWS Inspector work?

The material gives a simple workflow:

### Step 1 — Install the AWS Agent

Install the **AWS agent on your EC2 instances** for the host assessment.

### Step 2 — Run an Assessment

Run the assessment against your selected **assessment target**.

### Step 3 — Review Findings

AWS Inspector produces findings showing security issues.

### Step 4 — Remediate

Review those findings and **fix/remediate the security issues**.

```text
Install Agent
      ↓
Create/Select Assessment Target
      ↓
Run Assessment
      ↓
Review Findings
      ↓
Remediate Security Issues
```

---

# 5. 🔐 What is a Security Benchmark?

A **security benchmark** is a collection of security checks used to evaluate whether a system follows recommended security practices.

One important benchmark mentioned in the material is:

### CIS Benchmark

**CIS = Center for Internet Security**

The material highlights a CIS benchmark containing **699 checks**.

So for the exam:

> **CIS → Security benchmark → Security configuration checks**

---

# 6. Network vs Host Assessment

| Feature | Network Assessment | Host Assessment |
|---|---|---|
| Checks | Network configuration | Host/software/security configuration |
| Example | Ports reachable from outside VPC | Vulnerable software / CVEs |
| AWS Inspector Agent | ❌ Not required | ✅ Required |
| Focus | Network security | EC2 host security |

### 🧠 Easy memory trick

**Network = outside → ports/network**

**Host = inside → software/configuration**

---

# 7. AWS Inspector vs AWS Artifact

Don't mix these up:

| AWS Inspector | AWS Artifact |
|---|---|
| **Security assessment** | **Compliance reports** |
| Finds security vulnerabilities/issues | Provides AWS compliance documentation |
| Used for security assessment | Used for audits/compliance |
| Example: EC2 security benchmark | Example: SOC, ISO, PCI reports |

### 🔥 Exam shortcut

> **"Find vulnerabilities/security issues" → Inspector**

> **"Get AWS compliance reports" → Artifact**
