# 🔐 Encryption — TOL Format

## 1. WHAT?

### What is Cryptography?
**Cryptography** is the practice and study of techniques used for **secure communication in the presence of third-party adversaries**.

In simple words:  
> Cryptography = techniques used to protect information from attackers or unauthorized parties.

### What is Encryption?
**Encryption** is the process of **encoding/scrambling information using a key and a cipher** so that sensitive data becomes unintelligible and protected.

**Basic flow:**

`Plaintext + Key + Cipher → Encryption → Ciphertext`

- **Plaintext** → Original readable information
- **Key** → Secret value used by the encryption algorithm
- **Cipher** → Algorithm/method used for encryption
- **Ciphertext** → Encrypted, unreadable information

Example:

`"HELLO"` → 🔑 Encryption → `"X7@kP"` → 🔓 Decryption → `"HELLO"`

---

## 2. WHERE?

Encryption is used wherever **sensitive data needs protection**, such as:

- 💾 **Data at rest** — stored data
- 🌐 **Data in transit** — data moving across networks
- 🔐 Passwords and sensitive credentials
- ☁️ Cloud resources and storage
- 💳 Financial information
- 👤 Personal/customer information
- 🔑 Encryption keys and secrets

### In AWS
Encryption is commonly used with services such as:

- **Amazon S3** → encrypt objects
- **Amazon EBS** → encrypt volumes
- **Amazon RDS** → encrypt databases
- **AWS KMS** → create and manage encryption keys
- **AWS Secrets Manager** → protect secrets

> **Exam connection:** Encryption primarily supports **Confidentiality** in the CIA Triad.

## 3. HOW?

### Encryption Process

```text
              ENCRYPTION
Plaintext ──────────────────→ Ciphertext
    │                              │
    │        Key + Cipher          │
    └──────────────────────────────┘

              DECRYPTION
Ciphertext ─────────────────→ Plaintext
                 Key
```

### Step 1 — Start with Plaintext
The original readable data.

Example:

`AWS Cloud`

### Step 2 — Apply a Cipher
A **cipher** is the algorithm used to transform the data.

### Step 3 — Use a Key
The encryption process uses a **cryptographic key**.

### Step 4 — Produce Ciphertext
The result is unreadable without the appropriate decryption process.

`AWS Cloud → Encryption → 8fA#91x...`

### Step 5 — Decryption
The ciphertext is converted back into plaintext using the appropriate key/process.

# 🧠 Historical Example — Enigma

The slide uses the **Enigma machine** as an example of historical cryptography.

- Used during **World War II**
- Used different keys/settings
- Relied on **cipher substitution**
- Its purpose was to transform readable information into an unintelligible form.

This demonstrates the basic idea behind cryptography: **transform information so unauthorized parties cannot understand it.**

### ⚠️ Common Trap

Don't confuse:

**Encryption ≠ Hashing**

- **Encryption** → designed to be reversible through decryption.
- **Hashing** → generally one-way transformation used to produce a hash.

Also:

**Encoding ≠ Encryption**

- Encoding is primarily for **format/representation**.
- Encryption is for **security/protection**.
