# AWS Cost Explorer

## 1. 📖 Definition

**AWS Cost Explorer** is a tool that lets you **visualize, understand, and manage your AWS costs and usage over time**.

It helps you analyze where your AWS money is being spent and identify **cost drivers and usage trends**.

---

## 2. 🔍 What Is It / How Does It Work?

Cost Explorer provides a graphical view of your AWS costs and usage.

You can:

* Select a **specific date range**.
* View data at **daily or monthly** granularity.
* **Filter** your data.
* **Group** your data in different ways.
* Create and use different **reports**.
* Use **forecasting** to estimate future costs.

The screenshots show filtering/grouping by things such as:

* Service
* Linked Account
* Region
* Instance Type
* Usage Type
* Usage Type Group
* Resource
* Cost Category
* Tag
* API Operation
* Availability Zone
* Platform
* Purchase Option
* Tenancy

---

## 3. 🎯 Why Use It?

Cost Explorer is useful when you want to:

* Understand **where your AWS costs are coming from**.
* Analyze **usage trends over time**.
* Find expensive AWS services/resources.
* Compare costs between different services, accounts, or regions.
* Investigate specific spending using **filters and grouping**.
* Get an idea of **future costs using forecasting**.

---

## 4. ⚙️ How to Use It

### Step 1 — Select the time period

Choose the period you want to analyze.

Example:

**Last 6 months**

### Step 2 — Choose granularity

You can view the data at:

* **Daily**
* **Monthly**

### Step 3 — Apply filters

Filter the data to focus on specific resources or services.

Example from the screenshot:

**Service → EC2-Instances**

**Region → CA (Montreal)**

### Step 4 — Group the data

Use grouping to break down your costs.

For example:

**Group by → Service**

This allows you to see how much each service contributes to your total cost.

### Step 5 — Analyze the graph

Cost Explorer displays your costs visually, making it easier to identify spikes and trends.

### Step 6 — Use forecasting

Cost Explorer can provide a **forecast of future costs**, such as the expected month-end cost shown in the screenshot.

---

## 5. 📍 Where Is It?

**AWS Management Console → Cost Explorer**

Within Cost Explorer, you can access:

* Cost & usage analysis
* Filters
* Grouping
* Reports
* Forecasting

## 7. 🔮 Forecasting

Cost Explorer provides **forecasting** to give you an idea of your **future costs**.

For example, the screenshot shows:

> **Forecasted month-end costs: $456.94**

So instead of looking only at historical/current spending, you can use the forecast to estimate where your spending may end up.

---

## 8. 🧪 Scenario-Based Example

Suppose your AWS bill suddenly increases.

You can use **Cost Explorer** to investigate:

**Cost Explorer → Select date range → Filter by Service → EC2 → Group by Region**

You might discover that most of the increase is coming from **EC2 usage in a particular region**.

You can then investigate that area further.

## 9. 🆚 Cost Explorer vs Cost & Usage Report

| Feature        | Cost Explorer               | Cost & Usage Report (CUR)            |
| -------------- | --------------------------- | ------------------------------------ |
| Main purpose   | Visualize and analyze costs | Detailed cost/usage data             |
| Visualization  | ✅ Built-in                  | Requires other tools                 |
| Filtering      | ✅                           | Detailed data available              |
| Forecasting    | ✅                           | Not the focus shown in your material |
| Data format    | Visual reports              | CSV/GZIP or Parquet                  |
| S3 storage     | Not the focus               | ✅                                    |
| Athena         | Not required                | Can query CUR                        |
| Quick analysis | ✅                           | More detailed/advanced               |
