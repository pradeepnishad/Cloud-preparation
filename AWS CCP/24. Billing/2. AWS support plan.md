# ☁️ What are AWS Support Plans?

AWS Support Plans determine **how much help you get from AWS when something goes wrong**.

Think of it like:

```text
Basic
  ↓
Developer
  ↓
Business
  ↓
Enterprise
```

As you move upward:

* More technical support
* Faster response times
* More communication channels
* More AWS recommendations
* More enterprise-level assistance

---

# 🟢 1. Basic Support

### Cost: **$0**

Every AWS customer gets Basic Support automatically. ([AWS Documentation][2])

You get things such as:

* AWS documentation
* AWS forums
* AWS Health Dashboard
* Product FAQs
* Account/billing assistance
* Service quota-related assistance

But **you don't get general 24/7 technical troubleshooting with an AWS engineer** under Basic.

### Example

Your EC2 instance isn't working and you want an AWS engineer to troubleshoot it with you.

Basic Support isn't designed for that level of technical assistance.

### 🧠 Remember:

> **Basic = Free + account/billing + general AWS resources**

---

# 🟡 2. Developer Support

This is what the first slide calls **Developer**.

Historically, it provided technical support primarily through **email**, intended for development/testing workloads.

The old slide says:

> ~$29/month

and shows slower response times.

However, **Developer Support is being discontinued January 1, 2027**, and AWS stopped accepting new Developer Support subscriptions after December 2, 2025. ([AWS Documentation][1])

So don't memorize the old `$29 Developer` price as current AWS pricing.

---

# 🟠 3. Business Support

Historically, Business Support was aimed at **production workloads**.

It provided:

### 24/7 technical support

Through:

* Phone
* Chat
* Email

And faster response times than Developer.

For example, the old slide shows:

```text
Production System Impaired → <4 hours

Production System DOWN → <1 hour
```

The important concept is:

> **Business = production workload + 24/7 technical support**

But again, the old Business plan is being retired on **January 1, 2027**. ([Amazon Web Services, Inc.][3])

---

# 🔴 4. Enterprise Support

This is designed for **large organizations and business-critical workloads**.

One of the most important Enterprise features is:

## 👨‍💼 TAM — Technical Account Manager

A **TAM** is a designated AWS technical advisor who works with your organization.

They can help with things like:

* Architecture
* AWS best practices
* Risk management
* Cost optimization
* Operational planning
* Large-scale AWS deployments

The current Enterprise Support plan also provides **24/7 access to AWS Cloud Support Engineers** and a **15-minute response target for business-critical system downtime**. ([AWS Documentation][4])

---

# 😎 What is the "Personal Concierge"?

The old slide shows:

> 😎 Personal Concierge

This is essentially specialized **account/billing assistance** for Enterprise-level customers.

Think:

> **Technical Account Manager = technical/architectural relationship**

> **Concierge = account/billing assistance**

For the Cloud Practitioner exam, don't overthink the implementation details.

---

# 🧠 What is Trusted Advisor doing here?

This is important.

**AWS Trusted Advisor** analyzes your AWS environment and provides recommendations around areas such as:

* Cost optimization
* Performance
* Security
* Fault tolerance
* Service limits

([AWS Documentation][5])

Historically, the support plans determined how many Trusted Advisor checks you could access.

The slide says:

```text
Basic/Developer → 7 checks
Business/Enterprise → All checks
```

That's useful for understanding the **older exam material**, but the exact Trusted Advisor entitlements have evolved, so don't treat that old 7-vs-all table as a current pricing fact.

# 💰 The second slide: How was pricing calculated?

This is explaining that some old paid support plans weren't simply:

> "$29 every month"

Instead, AWS could calculate support fees based on **AWS monthly usage**, subject to a minimum.

### Developer example from the slide:

```text
$29 minimum
OR
3% of monthly AWS usage

whichever is greater
```

If your AWS usage was:

**$500**

3% × $500 = **$15**

But minimum = **$29**

Therefore:

### You pay $29

---

If your AWS usage was:

**$1,000**

3% × $1,000 = **$30**

Therefore:

### You pay $30

That's what the slide is demonstrating.

# 🔥 Current situation in 2026

This is the part I'd actually remember if you're using AWS today.

AWS currently lists:

### **Basic**

Free.

### **Business Support+**

The newer support offering replacing the old Developer/Business plans.

It provides AI-powered assistance plus **24/7 access to AWS experts**, with a **$29/month minimum** under the current pricing structure. ([Amazon Web Services, Inc.][3])

### **Enterprise Support**

For larger organizations requiring advanced support, including a designated TAM and 15-minute response for business-critical outages. ([AWS Documentation][4])

AWS also has **Unified Operations** for customers needing broader operational support. ([AWS Documentation][2])

# 🎯 For your Cloud Practitioner exam

Don't get stuck memorizing every dollar amount from this slide.

Focus on this:

| Plan                        | Think of it as                                     |
| --------------------------- | -------------------------------------------------- |
| 🟢 **Basic**                | Free, account/billing + AWS resources              |
| 🟡 **Developer** *(legacy)* | Development/testing support                        |
| 🟠 **Business** *(legacy)*  | Production + 24/7 technical support                |
| 🔴 **Enterprise**           | Mission-critical + TAM + fastest critical response |

### ⭐ Most important exam associations

**Free AWS support?**

→ **Basic**

**Production workload needs 24/7 technical support?**

→ **Business / current Business Support+**

**Large enterprise wants a dedicated technical advisor?**

→ **Enterprise + TAM**

**Business-critical system is down and the company needs the fastest response?**

→ **Enterprise**

**AWS service that gives recommendations about cost, security, performance, etc.?**

→ **Trusted Advisor**
