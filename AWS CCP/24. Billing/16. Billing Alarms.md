# AWS Billing Alerts / Alarms

## 1. 📖 Definition

**Billing Alerts / Alarms** are **CloudWatch Alarms** that can be used to monitor your AWS spending.

They allow you to define a spending threshold and receive an alert when your estimated AWS charges reach that threshold.

The screenshot specifically describes these as **“Billing Alarms.”**

---

## 2. 🔍 What Is It / How Does It Work?

AWS provides billing information as a metric that can be monitored through **Amazon CloudWatch**.

The basic process is:

**AWS spending → Billing metric → CloudWatch Alarm → Threshold reached → Notification**

The screenshot shows the **`EstimatedCharges`** metric being used.

For example:

> You want to know when your AWS spending reaches **$50**.

You can create a CloudWatch billing alarm with:

* **Metric:** Billing
* **Metric name:** `EstimatedCharges`
* **Currency:** USD
* **Condition:** Estimated charges ≥ $50

When the condition is met, the alarm can trigger a notification.

---

## 3. 🎯 Why Use It?

Billing Alarms are useful when you want to:

* Monitor AWS spending.
* Get notified when charges reach a particular amount.
* Track estimated charges automatically.
* Create more customized/complex monitoring conditions.
* Monitor spending through **CloudWatch**.

The screenshot specifically points out that **Billing Alarms are more flexible than AWS Budgets** for more complex spending and usage monitoring use cases.

---

## 4. ⚙️ How to Use It

### Step 1 — Enable Billing Alerts

First, turn on **Billing Alerts** in your AWS **Cost Management Preferences**.

### Step 2 — Open CloudWatch

Go to **Amazon CloudWatch**.

### Step 3 — Create an Alarm

Create a new **CloudWatch Alarm**.

### Step 4 — Select Billing

Choose **Billing** as the metric.

### Step 5 — Select the Metric

Use the **EstimatedCharges** metric.

### Step 6 — Define the Condition

Specify the threshold at which the alarm should trigger.

Example:

**EstimatedCharges ≥ $50**

### Step 7 — Configure Notification

Configure the notification for when the alarm enters the alert state.

You need to enable **Billing Alerts** first.

### Billing Alarm

**Amazon CloudWatch → Alarms → Create Alarm → Billing**

### Billing Metric

**Billing → `EstimatedCharges`**

## 7. 🆚 Billing Alarm vs AWS Budgets

| Feature      | Billing Alarm                        | AWS Budgets                    |
| ------------ | ------------------------------------ | ------------------------------ |
| Main service | **CloudWatch**                       | **AWS Budgets**                |
| Purpose      | Monitor spending through alarms      | Set and monitor budgets        |
| Metric       | Billing / `EstimatedCharges`         | Cost, usage, reservation, etc. |
| Flexibility  | More flexible for complex monitoring | Easier for budget management   |
| Alerts       | CloudWatch alarm                     | Budget threshold alerts        |

**From your screenshot:** Billing Alarms are described as **more flexible than AWS Budgets** and suitable for more complex spending/usage monitoring.
