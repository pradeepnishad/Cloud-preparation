# AWS Budgets 💰

## 1. What is AWS Budgets?

**AWS Budgets** allows you to **set a budget and receive alerts when your actual or forecasted AWS usage/cost approaches or exceeds that budget.**

Think of it as:

> **"I don't want my AWS spending to go above ₹/$X → AWS Budgets warns me."**

---

## 2. What can you create a budget for?

According to your slide, you can create:

* **Cost Budget** → Monitor money spent
* **Usage Budget** → Monitor usage, such as hours
* **Reservation Budget** → Monitor reservations

### Example

You set:

> **Monthly budget = $100**

If your spending reaches a defined threshold, AWS can send you an alert.

---

## 3. Budget Periods 📅

Budgets can be tracked at:

* **Monthly**
* **Quarterly**
* **Yearly**

You can also configure **start and end dates**.

---

## 4. What can AWS Budgets monitor?

Your slide specifically mentions reservation alerts for:

* **EC2**
* **RDS**
* **Redshift**
* **ElastiCache**

---

## 5. Alerts 🚨

You can define a threshold for when you want to be notified.

For example:

```text
Budget = $100

Actual cost
   ↓
$50 → No alert
$80 → ⚠️ Alert
$100 → 🚨 Budget exceeded
```

The slide says notifications can be provided through **email or Chatbot**.

---

## 6. Actual vs Forecasted Cost

AWS Budgets can alert you based on:

### Current/Actual cost

How much you've **already spent**.

### Forecasted cost

How much AWS expects you **may spend** based on the forecast.

Example:

```text
Budget = $100

Current spending = $70
Forecasted spending = $120

→ AWS Budget can alert you
```

---

## 7. AWS Budgets vs Cost Explorer

| AWS Budgets                       | Cost Explorer             |
| --------------------------------- | ------------------------- |
| Set a **budget**                  | Analyze your AWS costs    |
| Creates **alerts**                | Visualize usage/cost      |
| Tracks cost/usage/reservations    | Detailed cost analysis    |
| Helps prevent unexpected spending | Helps understand spending |

Your slide specifically says AWS Budgets can be used to **forecast costs**, but is more limited compared with **Cost Explorer** or detailed **Cost & Usage Reports + BI tools**.

---

## 8. AWS Budgets Dashboard

From your second slide, you can:

* View your list of budgets
* See **budget history**
* Download budget information as **CSV**
* View current/forecasted amounts
* See whether a budget has been **exceeded**

---

## 9. Cost of AWS Budgets 💵

According to your slide:

* **First 2 budgets → Free**
* Each additional budget → **$0.02/day**
* Approximately **$0.60/month per budget**
* Maximum **20,000 budgets**

# AWS Budget Reports 📊

## 1. What is AWS Budget Report?

**AWS Budget Report** is used **alongside AWS Budgets** to create and send reports about your AWS Budgets.

The report can be automatically emailed to **specific email addresses**, so you don't have to keep logging into the AWS Management Console.

---

## 2. What does it do?

Think of it like this:

```text
AWS Budgets
     ↓
Create Budget Report
     ↓
Choose frequency
     ↓
Daily / Weekly / Monthly
     ↓
Report sent to email 📧
```

It helps you **stay on top of your AWS budget performance**.

---

## 3. Report Frequency 📅

According to the slide, reports can be sent:

* **Daily**
* **Weekly**
* **Monthly**

You can specify the **email recipients** who should receive the report.

---

## 4. Why use Budget Reports?

Without Budget Reports:

```text
Want to check budget
       ↓
Login to AWS Console
       ↓
Open AWS Budgets
       ↓
Check status
```

With Budget Reports:

```text
AWS Budget
    ↓
Automatic report
    ↓
📧 Email
    ↓
Check without logging into console
```

So it's mainly about **convenience and regular reporting**.

---

## 5. AWS Budgets vs Budget Reports

| AWS Budgets                      | AWS Budget Reports              |
| -------------------------------- | ------------------------------- |
| Creates and tracks budgets       | Creates reports about budgets   |
| Can trigger alerts               | Sends scheduled reports         |
| Monitors cost/usage/reservations | Keeps you updated through email |
| Focus = **budget monitoring**    | Focus = **budget reporting**    |

### Simple example

You create:

> **Monthly AWS Budget = $100**

Then create a **weekly Budget Report**.

AWS can send the budget information to your specified email regularly.

---
