## AWS Marketplace

**AWS Marketplace** is an **online store/catalog where you can find, buy, deploy, and manage third-party software and services that run on AWS.**

Think of it like an **app store for AWS**.

### What can you find there?

Examples include:

* 🔐 Security software
* 🖥️ Operating systems
* 🗄️ Database software
* 🛠️ DevOps tools
* 🤖 AI/ML solutions
* 🌐 Networking products
* 📊 Monitoring tools
* Enterprise applications

These products can come from **third-party vendors**, not just AWS.

### How it works

A typical flow is:

**Find product**
↓
**Choose pricing/license**
↓
**Subscribe**
↓
**Deploy/use it on AWS**

Depending on the product, the pricing may be:

* Free
* Free trial
* Hourly/monthly usage
* Subscription
* Pay-as-you-go

### Simple example

Suppose your company needs a particular **security appliance** for its AWS environment.

Instead of manually finding the vendor, purchasing software separately, and figuring out deployment, you can find the product through **AWS Marketplace** and deploy it within your AWS environment.

---

### ⭐ Cloud Practitioner exam point

**AWS Marketplace ≠ AWS services**

AWS Marketplace provides access to **third-party software and solutions** that can be used with AWS.

### 🧠 Easy memory

> **AWS Marketplace = Store for finding and purchasing third-party software/solutions for AWS.**
