## AWS Cost and Usage Reports (CUR)

### 🎯 T — Topic

**AWS Cost and Usage Reports (CUR)**

### 📌 O — Overview

AWS **Cost and Usage Report (CUR)** generates a **detailed spreadsheet/report** that helps you **analyze and understand AWS costs** in greater detail.

### 🔑 L — Learn / Key Points

* 📊 **Detailed spreadsheet** → Provides detailed AWS cost and usage information.
* ⏱️ **Data granularity** → You can choose:

  * **Hourly**
  * **Daily**
  * **Monthly**
* 🏷️ **Cost Allocation Tags** → The report contains Cost Allocation Tags.
* 🪣 **Storage** → CUR data is stored in a selected **Amazon S3 bucket**.
* 📄 **Formats** → Data can be stored as:

  * **CSV (GZIP)**
  * **Parquet**
* 🔍 **Amazon Athena** → Can be used to turn the report into a **queryable database**.
* 📈 **Amazon QuickSight** → Can be used to visualize billing data as **graphs**.

### 🧠 Exam Shortcut

**CUR = Detailed cost & usage analysis**

Remember the flow:

**CUR → S3 → Athena → QuickSight**

> **CUR** creates the detailed report → **S3** stores it → **Athena** queries it → **QuickSight** visualizes it.
