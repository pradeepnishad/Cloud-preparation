# 🔐 AWS Account ID

## 1. Definition

Every AWS Account has a **unique Account ID**.

The **AWS Account ID** is a **12-digit number** that uniquely identifies an AWS account.

Examples:

```text
123456789012
121212121212
498241098510
```

Simple definition:

> **AWS Account ID = A unique 12-digit identifier for an AWS account.**

---

# 2. What Is the AWS Account ID?

Every AWS account is assigned its own unique 12-digit Account ID.

You can generally find your Account ID by opening the **current user/account menu** in the AWS Management Console.

```text
AWS Management Console
        ↓
Current User / Account Menu
        ↓
My Account
        ↓
Account ID
```

---

# 3. Why Is the AWS Account ID Used?

The Account ID is used in several AWS operations.

### ① Signing in as an IAM user

When signing in using an IAM user, the **12-digit Account ID or account alias** can be used.

```text
Sign in as IAM user

Account ID (12 digits) or account alias
IAM user name
Password
```

---

### ② Cross-account roles

AWS Account IDs can be used when working with **cross-account roles**.

For example:

```text
AWS Account A
      ↓
Cross-account role
      ↓
AWS Account B
```

The Account ID helps identify the AWS account involved.

---

### ③ AWS Support Cases

The AWS Account ID can also be used when dealing with **AWS Support cases**.

---

# 4. How to Find Your AWS Account ID

From the AWS Management Console:

```text
AWS Management Console
        ↓
Click current user/account
        ↓
My Account
        ↓
View Account ID
```

The Account ID consists of **12 digits**.

---

# 5. Security Consideration

It is generally good practice to **keep your Account ID private where practical**, because it is one of the pieces of information that can be used to identify an AWS account.

However:

> **The Account ID is not a password or secret credential.**

Knowing an Account ID alone does **not** give someone access to your AWS resources.

Your actual authentication credentials, such as passwords, access keys, and other authentication factors, must be protected.

---

# 6. Scenario-Based Example

Suppose you have two AWS accounts:

```text
Development Account
Account ID: 123456789012

Production Account
Account ID: 987654321098
```

You want a role in the Development account to access resources in Production.

```text
Development Account
123456789012
       ↓
Cross-account role
       ↓
Production Account
987654321098
```

The Account IDs help identify the accounts involved in the cross-account access configuration.
