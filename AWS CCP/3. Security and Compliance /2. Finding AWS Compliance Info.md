# 🔐 Finding AWS Compliance Information

## 1. Definition

**AWS compliance information** refers to the documentation, reports, certifications, and resources that show how AWS meets various **security, privacy, regulatory, and compliance requirements**.

In simple words:

> **AWS provides information and evidence that helps customers understand how AWS complies with security and regulatory standards.**

Examples of compliance standards include:

* ISO standards
* SOC reports
* PCI DSS
* HIPAA-related requirements
* GDPR
* FedRAMP

---

## 2. What Is It / How Does It Work?

AWS operates under various compliance frameworks and provides customers with documentation that can help them with their **own compliance requirements**.

Think of it like:


Regulation / Standard
        ↓
     AWS
        ↓
Compliance certifications
Reports + documentation
        ↓
Customer uses this information
        ↓
Builds compliant applications


AWS provides resources through its **AWS Compliance Center** and **AWS Artifact**.

### AWS Artifact

**AWS Artifact** is a service that provides **on-demand access to AWS security and compliance documents**.

For example, customers can access certain:

* AWS compliance reports
* Certifications
* Agreements
* Other compliance-related documentation

---

# 3. Why Do We Need AWS Compliance Information?

Organizations often have legal, regulatory, or industry requirements.

For example:

> A company handling credit-card information may need to demonstrate that its cloud infrastructure meets relevant PCI DSS requirements.

Instead of starting from zero, the company can use AWS compliance documentation as part of its compliance process.

Benefits include:

* Understand AWS compliance posture
* Support audits
* Obtain compliance documentation
* Help meet regulatory requirements
* Reduce the effort required to evaluate AWS

---

# 4. How to Find AWS Compliance Information

The main places to know are:

### 🏛️ AWS Compliance Center

Provides information about AWS compliance programs and certifications.


AWS Compliance Center
        ↓
Compliance programs
        ↓
Standards / regulations
        ↓
AWS compliance information


### 📄 AWS Artifact

Provides access to AWS compliance documents and reports.


AWS Console
     ↓
AWS Artifact
     ↓
Compliance reports / documents
     ↓
Review required information


**Exam tip:** If the question specifically asks where to obtain **AWS compliance reports and agreements**, think **AWS Artifact**.

---

# 5. When Should You Use It?

AWS compliance information is particularly useful when:

* Your organization must meet regulatory requirements
* You're preparing for an audit
* You're evaluating AWS for a regulated workload
* Your security/compliance team needs AWS documentation
* You need evidence about AWS's compliance certifications
* You're moving an existing regulated application to AWS

---

# 6. Scenario-Based Example

Imagine a financial company wants to move an application to AWS.

The company's compliance team asks:

> "What security and compliance certifications does AWS have, and what documentation can we review?"

The company can use AWS compliance resources and **AWS Artifact** to obtain relevant AWS compliance documentation.


Financial Company
       ↓
Needs compliance evidence
       ↓
AWS Compliance resources
       ↓
AWS Artifact
       ↓
Relevant reports / certifications
       ↓
Compliance team reviews them


The company can then use this information when assessing its own compliance requirements.

---

# 7. Important: AWS Compliance ≠ Your Entire Compliance

This is **very important** and connects directly to the Shared Responsibility Model.

Just because AWS is compliant with a particular standard does **not automatically mean your application is compliant**.

For example:


AWS
 ↓
Secures underlying cloud infrastructure
 ↓
Provides compliance certifications/reports

Customer
 ↓
Configures application
 ↓
Controls access
 ↓
Protects data
 ↓
Maintains required customer-side controls


So:

> **AWS compliance helps you meet your compliance obligations, but you are still responsible for your own compliance responsibilities.**
