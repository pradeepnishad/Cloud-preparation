# 🔐 AWS Multi-Factor Authentication (MFA / 2FA)

## 1. Definition

**Multi-Factor Authentication (MFA)** is a security mechanism that requires **more than one authentication factor** to verify a user's identity.

Simple definition:

> **MFA = Password + an additional authentication factor.**

It provides an additional layer of security if a password is compromised.

---

# 2. What Is MFA / How Does It Work?

Normally, you might authenticate using:


Username + Password
        ↓
       Login


With MFA:


Username + Password
        +
MFA code / security key
        ↓
      Login


So even if someone steals your password, they still need the additional authentication factor.

---

## Authentication Factors

The factors generally fall into categories such as:

### 🔑 Something you know

Examples:

* Password
* PIN

### 📱 Something you have

Examples:

* Authenticator device/app
* Hardware security key

### 👤 Something you are

Examples:

* Fingerprint
* Facial recognition

For AWS, MFA commonly involves an authentication device or application in addition to your password.

---

# 3. Why Use MFA?

The main purpose is to **protect AWS accounts and identities from unauthorized access**.

Without MFA:


Attacker gets password
       ↓
      Login
       ↓
❌ Account compromised


With MFA:


Attacker gets password
       ↓
      Login
       ↓
MFA required
       ↓
Attacker doesn't have MFA
       ↓
❌ Access blocked


### Benefits

* 🔐 Stronger account security
* 🛡️ Protection against stolen passwords
* 🚫 Reduces unauthorized access
* 🔒 Adds an additional security layer

---

# 4. How to Use MFA in AWS

You can configure MFA for AWS identities such as:

* **Root user**
* **IAM users**
* Other supported identity/access configurations

A common setup is an authenticator application.

The general process is:


AWS Identity
     ↓
Enable MFA
     ↓
Configure authentication device/app
     ↓
Login with password
     ↓
Enter MFA code
     ↓
Authenticated


For highly sensitive access, hardware security keys can also be used.

---

# 5. When Should You Use MFA?

For AWS security, MFA should be used especially for **privileged and sensitive access**.

### ⭐ Most important:

**Enable MFA on the AWS root user.**

You should also protect administrative identities with strong authentication.

For example:


Root User
    ↓
Password
    +
MFA
    ↓
Account access


This is one of the first security steps you should take when creating an AWS account.

---

### With MFA:

MFA therefore provides an **additional layer of protection**.

---

# 7. MFA vs 2FA

You will often see **MFA** and **2FA** used together, but they aren't exactly identical.

### 2FA — Two-Factor Authentication

Requires **exactly two authentication factors**.

Example:


Password
   +
MFA code
   ↓
Login


### MFA — Multi-Factor Authentication

Requires **two or more authentication factors**.

So:

> **2FA is a type of MFA.**

For your Cloud Practitioner exam, you'll frequently see AWS documentation simply use the term **MFA**.

---

# 8. MFA vs Password

| Password only                     | MFA                             |
| --------------------------------- | ------------------------------- |
| One authentication factor         | Multiple factors                |
| Weaker protection                 | Stronger protection             |
| Password theft can lead to access | Password alone isn't sufficient |
| Basic authentication              | Additional security layer       |

Watch for these phrases:

> **"Additional layer of security"**

→ **MFA**

> **"Protect the AWS root user"**

→ **Enable MFA**

> **"Password + authentication code"**

→ **MFA / 2FA**

> **"Protect against compromised credentials"**

→ **MFA**

> **"Two authentication factors"**

→ **2FA**

### ⭐ Very common exam question

**Q: What should you do to protect the AWS root user?**

**A: Enable MFA and avoid using the root user for everyday tasks.**
