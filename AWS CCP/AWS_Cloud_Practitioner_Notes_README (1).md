## 📝 What the Notes Cover

The notes focus on understanding AWS concepts through:

- Definitions and simple explanations
- Core AWS services
- Security and compliance
- Networking and connectivity
- Compute, storage and databases
- Identity and access management
- Application integration
- Containers and serverless
- Governance and provisioning
- Logging and monitoring
- AWS architecture
- TCO and migration
- Billing
- Service comparisons and variations

The goal is to understand **what a service does, why it is used, and how it differs from similar AWS services**.
