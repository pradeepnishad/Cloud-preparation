## CAPEX vs OPEX — AWS Cloud Practitioner Notes

This slide compares **Capital Expenditure (CAPEX)** and **Operational Expenditure (OPEX)**.

### 1. Capital Expenditure (CAPEX)

**CAPEX = spending money upfront on physical infrastructure.**

You purchase infrastructure before you use it.

Examples from the slide:

* 🖥️ Server costs — computers
* 💾 Storage costs — hard drives
* 🌐 Network costs — routers, cables, switches
* 💿 Backup and archive costs
* 🔄 Disaster recovery costs
* 🏢 Data-center costs — rent, cooling, physical security
* 👨‍💻 Technical personnel

### Key idea

With CAPEX:

> **You have to estimate upfront how much you need to spend.**

For example, suppose a company expects to need 100 servers. It may have to purchase those servers **before** they are actually needed.

This creates a risk of **overprovisioning** or **underprovisioning**.

---

# 2. Operational Expenditure (OPEX)

**OPEX = ongoing costs associated with operating/using a service.**

In the cloud, much of the physical infrastructure cost is handled by the **cloud provider**.

The customer focuses more on **non-physical costs** and consumption.

Examples from the slide:

* Software leasing/customization
* Employee training for cloud services
* Cloud support
* Cloud usage/billing

Cloud billing can be based on metrics such as:

* **Compute usage**
* **Storage usage**

### Key idea

With OPEX:

> **You can try a product or service without investing in the equipment upfront.**

---

# 3. Simple Example

Imagine you need a server for your application.

### Traditional On-Premises — CAPEX

You might need to:

**Buy server → buy storage → buy networking equipment → install → secure → maintain**

You spend money **upfront**.

### Cloud — OPEX

Instead:

**Create cloud resources → use them → pay according to usage**

You don't need to purchase the physical server yourself.

---

# 4. CAPEX vs OPEX

| CAPEX                     | OPEX                         |
| ------------------------- | ---------------------------- |
| Capital Expenditure       | Operational Expenditure      |
| Spend upfront             | Pay as you operate/use       |
| Physical infrastructure   | Service/usage-oriented costs |
| Buy servers               | Use cloud compute            |
| Buy storage               | Pay for storage usage        |
| Buy networking equipment  | Use cloud networking         |
| Requires upfront planning | More flexible                |
| Large initial investment  | No large hardware investment |
| Common in on-premises     | Common cloud spending model  |

### 🧠 Easy exam memory

**CAPEX → "Buy it first."**

**OPEX → "Use it and pay for it."**

---

### ⭐ Very important for AWS exams

If the question says:

> **"Avoid large upfront infrastructure investment"**

Think **OPEX / cloud**.

If it says:

> **"Purchase servers, storage, networking equipment upfront"**

Think **CAPEX / on-premises**.

And remember:

**CAPEX = Capital → physical assets + upfront investment**

**OPEX = Operational → ongoing operating/usage costs**
