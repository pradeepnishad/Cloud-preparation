# Windows on AWS

AWS provides multiple services and tools that make it easier to **run, manage, store, develop, and migrate Windows workloads on AWS**.

Your source highlights the following services:

---

## 1. Windows Server on Amazon EC2

### Definition
You can run **Windows Server as an EC2 instance**.

AWS provides multiple Windows Server versions from which you can select when launching an EC2 instance.

### Why use it?
When you need a Windows-based virtual server for:
- Windows applications
- Windows Server workloads
- Enterprise applications
- Custom software

### Example

```text
AWS EC2
   ↓
Windows Server
   ↓
Install your application
```

### Key point
**Windows Server → EC2**

---

## 2. SQL Server on Amazon RDS

### Definition
Amazon RDS supports **Microsoft SQL Server** as one of its database engines.

You can select from supported SQL Server database versions when creating an RDS database.

### Why use it?
When your application requires a **managed Microsoft SQL Server database** without wanting to manage the underlying database infrastructure yourself.

### Example

```text
Windows Application
        ↓
Amazon RDS
        ↓
Microsoft SQL Server
```

### Key point
**SQL Server → RDS**

---

## 3. AWS Directory Service

### Definition
AWS Directory Service allows you to run **Microsoft Active Directory (AD) as a managed service**.

This is particularly relevant for organizations running Windows environments.

### Why use it?
For capabilities involving:
- User identities
- Authentication
- Windows domain environments
- Active Directory

### Example

```text
Users
  ↓
Active Directory
  ↓
Windows resources
```

### Key point

**Microsoft Active Directory → AWS Directory Service**

---

## 4. AWS License Manager

### Definition
AWS License Manager helps you **manage software licenses** from software vendors such as Microsoft.

### Why use it?
Organizations may have many software licenses that need to be tracked and managed across their AWS environment.

### Example

```text
Microsoft licenses
        ↓
AWS License Manager
        ↓
Track / manage licenses
```

### Key point

**Software licenses → AWS License Manager**

---

## 5. Amazon FSx for Windows File Server

### Definition
Amazon FSx for Windows File Server is a **fully managed, scalable file storage service built for Windows**.

It provides Windows-compatible file storage.

### Why use it?
When Windows applications or users need managed file storage designed for Windows environments.

### Example

```text
Windows Applications
        ↓
FSx for Windows File Server
        ↓
Files
```

### Key point

**Windows file storage → FSx for Windows File Server**

---

## 6. AWS SDK

### Definition
AWS SDKs allow developers to **write code in their preferred programming language to interact with AWS APIs**.

The source specifically highlights **.NET** as a language commonly used by Windows developers.

### Why use it?

Instead of manually interacting with AWS through the console, developers can write applications that communicate with AWS programmatically.

```text
.NET Application
       ↓
AWS SDK
       ↓
AWS API
       ↓
AWS Service
```

### Key point

**Windows/.NET development → AWS SDK**

---

## 7. Amazon WorkSpaces

### Definition
Amazon WorkSpaces allows you to run a **virtual desktop**.

The source describes it as allowing you to launch a **Windows 10 desktop** that provides a secure and durable workstation accessible through an Internet connection.

### Why use it?

Useful when users need a cloud-hosted desktop that they can access remotely.

### Example

```text
User
 ↓
Internet
 ↓
Amazon WorkSpaces
 ↓
Windows Desktop
```

### Key point

**Virtual Windows desktop → Amazon WorkSpaces**

---

## 8. AWS Lambda + PowerShell

### Definition
AWS Lambda supports **PowerShell** as a programming language/runtime for writing serverless functions.

This allows Windows-oriented developers and administrators to use PowerShell for serverless automation.

### Example

```text
Event
 ↓
AWS Lambda
 ↓
PowerShell code
 ↓
AWS action
```

### Why use it?

Useful when you want to perform automation without managing a server.

### Key point

**PowerShell serverless functions → AWS Lambda**

---

## 9. AWS Migration Acceleration Program (MAP)

### Definition
The **AWS Migration Acceleration Program (MAP)** is a methodology/program designed to help organizations migrate workloads to AWS.

Your source specifically mentions **Windows migrations** and AWS Partners that provide professional services for MAP.

### Why use it?

Useful for organizations moving large enterprise Windows workloads from existing environments to AWS.

### Key point

**Large enterprise migration → AWS MAP**

---
