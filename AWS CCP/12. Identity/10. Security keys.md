# 🔐 Security Keys

## 1. Definition

A **security key** is a physical device used as a **second step in the authentication process** to gain access to a device, workstation, or application.

It is therefore commonly used as an **MFA factor**.

Simple flow:

```text
Username + Password
        ↓
Security Key
        ↓
Authentication
        ↓
Access granted
```

---

## 2. What Does a Security Key Look Like?

A security key can look similar to a **USB flash drive**.

Your screenshot shows a **YubiKey** as an example of a popular security-key brand.

The key can be connected to a computer, and the user may interact with it—for example, by touching a button on the device.

---

## 3. How Does It Work?

According to your source, when your finger makes contact with the button/exposed metal on the device, it can **generate and autofill a security token**.

Conceptually:

```text
User enters password
        ↓
Connect/use security key
        ↓
Touch security key
        ↓
Security token / authentication
        ↓
Access granted
```

The important point is that the user needs **physical possession of the security key**.

---

# 4. Security Key as MFA

A security key can provide the **"something you have"** factor.

For example:

```text
Something you know
        ↓
Password

        +

Something you have
        ↓
Security Key

        ↓
MFA
```

This means an attacker who only knows your password doesn't automatically have the physical security key.

# 🎯 Scenario

Imagine you are logging into an important AWS account.

```text
Step 1
Username + Password
        ↓
Step 2
Security Key
        ↓
Touch/Use Key
        ↓
Authentication successful
        ↓
AWS access
```

If someone steals your password but doesn't possess your security key, the password alone isn't sufficient to complete this authentication flow.

---

# 🔥 Security Key vs Authenticator App

Both can be used as additional authentication factors, but they work differently.

|            | Security Key                  | Authenticator App         |
| ---------- | ----------------------------- | ------------------------- |
| Form       | Physical device               | Mobile application        |
| Example    | YubiKey                       | Authenticator app         |
| Factor     | Something you have            | Something you have        |
| Connection | USB/NFC/etc. depending on key | Phone/app                 |
| Purpose    | Additional authentication     | Additional authentication |
