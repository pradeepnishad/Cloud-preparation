# 📁 Directory Service

## 1. Definition

A **directory service** is a shared information system that helps **map the names of network resources to their network addresses**.

From your source:

> **A directory service maps the names of network resources to their network addresses.**

Simple example:

```text
Resource name
     ↓
"Server01"
     ↓
Directory Service
     ↓
Network address
```

So instead of users needing to remember network addresses for every resource, they can use meaningful names.

---

## 2. What Does a Directory Service Manage?

According to your source, a directory service provides shared infrastructure for:

* **Locating**
* **Managing**
* **Administering**
* **Organizing**

network resources.

These resources can include:

* Volumes
* Folders
* Files
* Printers
* Users
* Groups
* Devices
* Telephone numbers
* Other objects

Think of it as a **centralized directory of network objects and their information**.

---

# 3. Directory Objects

An important concept from the screenshot is that **each network resource is considered an object** by the directory server.

For example:

```text
Directory
│
├── Users
│    ├── User1
│    └── User2
│
├── Groups
│    ├── Developers
│    └── Admins
│
├── Computers
│    ├── PC01
│    └── PC02
│
└── Printers
     ├── Printer01
     └── Printer02
```

Information about each object is stored as a **collection of attributes**.

For example:

```text
User01
 ├── Name
 ├── Department
 ├── Email
 └── Other attributes
```

The exact attributes depend on the type of object.

---

# 4. Directory Server

A **directory server** is the server that provides the directory service.

The relationship is:

```text
Clients
  │
  ├──────────┐
  │          │
  ↓          ↓
Directory Server
       │
       ↓
Directory Service
```

The clients can query the directory service to locate or obtain information about network resources.

---

# 5. Why Use a Directory Service?

Without a centralized directory, an organization would have to manage information about users, computers, printers, files, and other resources in many different places.

A directory service provides a **centralized information infrastructure** for managing and organizing those resources.

### Scenario

Imagine a company with:

* 1,000 employees
* 500 computers
* 100 printers
* Many groups and network resources

A directory service can maintain information about these objects centrally.

A client can query the directory instead of having to manually know where every resource is located.

---

# 6. Directory Service vs DNS

Don't confuse these two.

### DNS

Primarily maps:

```text
Domain name
     ↓
IP address
```

Example:

```text
example.com
     ↓
IP address
```

### Directory Service

Maintains information about **many types of network objects**, such as:

```text
Users
Groups
Computers
Printers
Files
Devices
```

and their associated attributes.

So:

> **DNS → primarily name resolution**

> **Directory Service → organized information about network resources/objects**

| **Directory Service** | Shared information infrastructure for network resources |
