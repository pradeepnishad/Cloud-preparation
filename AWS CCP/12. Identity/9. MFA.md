# 🔐 Multi-Factor Authentication (MFA)

## 1. Definition

**Multi-Factor Authentication (MFA)** is a security control that requires a user to provide **more than one authentication factor** before access is granted.

Your screenshot gives this flow:

```text
Username / Email
       +
Password
       ↓
Second device / factor
       ↓
Verification
       ↓
Access granted
```

The example shows a user entering their username and password and then confirming the login using a **phone with a verification code**.

---

# 2. Why Use MFA?

The main purpose highlighted in your source is:

> **MFA protects against people who have stolen your password.**

For example, suppose someone obtains your password.

### Without MFA

```text
Attacker
   ↓
Stolen password
   ↓
Login
   ↓
❌ Access
```

### With MFA

```text
Attacker
   ↓
Stolen password
   ↓
Needs second factor
   ↓
Cannot complete verification
   ↓
❌ Access blocked
```

So even if the password is compromised, the attacker may not be able to authenticate.

---

# 3. Authentication Factors

MFA is based on using multiple factors.

### Something you know

Examples:

* Password
* PIN

### Something you have

Examples:

* Phone
* Hardware security key
* Authenticator device

### Something you are

Examples:

* Fingerprint
* Face recognition
* Other biometric information

Your screenshot specifically demonstrates:

```text
Something you know
       ↓
Password

       +

Something you have
       ↓
Phone / verification code
```

---

# 4. One Factor vs Two-Factor / Multi-Factor

The screenshot shows the distinction:

### One Factor

```text
Username + Password
        ↓
One authentication factor
```

### Two-Factor Authentication (2FA)

```text
Password
   +
Second factor
   ↓
Access
```

### MFA

**MFA** means authentication using **multiple factors**.

So:

> **2FA is a type of MFA.**

Think:

```text
MFA
├── 2 factors
├── 3 factors
└── More factors
```

Imagine you log into AWS.

### Step 1

```text
Username
+
Password
```

### Step 2

AWS requests your additional authentication factor:

```text
Authenticator / Security Key / Other supported factor
```

### Step 3

The additional factor is successfully verified.

```text
Password ✅
+
Second factor ✅
       ↓
Access granted
```

This adds an additional layer of protection to the account.

# 6. Where Is MFA Used?

Your source states that MFA is available with:

* **Most cloud providers**
* Social media platforms such as Facebook

In AWS specifically, MFA is particularly important for protecting privileged identities such as the **root user**.
