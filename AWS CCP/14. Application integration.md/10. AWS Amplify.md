## AWS Amplify

### Definition

**AWS Amplify** is an **opinionated framework and fully managed infrastructure** that helps developers build web and mobile applications while focusing more on the application itself rather than underlying infrastructure.

### Main Amplify Components

* **AWS Amplify CLI** → unified toolchain to create, integrate, and manage AWS cloud services.
* **AWS Amplify SDK** → connects AWS services to client-side application code.
* **AWS Amplify UI** → accessible, themeable React components that connect to cloud functionality.
* **AWS Amplify Hosting** → static website hosting platform.
* **AWS Amplify Studio** → visual development environment for building full-stack web and mobile applications.

### AWS Service Integrations

| AWS Service        | Amplify use                      |
| ------------------ | -------------------------------- |
| **Amazon Cognito** | Authentication, sign-up/sign-in  |
| **API Gateway**    | REST APIs                        |
| **AppSync**        | GraphQL APIs                     |
| **S3**             | Storage / static website hosting |
| **DynamoDB**       | Backend database                 |
| **Lambda**         | Custom resolvers                 |

### Scenario

Suppose you're building a mobile shopping application:

```text
Mobile/Web App
      ↓
    Amplify
   ↙  ↓   ↘
Cognito AppSync S3
          ↓
      DynamoDB
```

Amplify helps connect these AWS services to the application without requiring the developer to manually build every piece of infrastructure integration.

### When to use it

Use Amplify when you want to **quickly develop and deploy web/mobile applications using AWS services**, particularly when you want a more streamlined developer experience.
